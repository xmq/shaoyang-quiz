# 大学生模拟体验与修复闭环

两位互不读取对方报告的代理分别模拟零基础新生、有少量编程与数学基础的大学生，实际阅读讲义、预测中间状态、先做例题、隐藏答案独立作答，再在浏览器中走学习闭环。不是招募真人，不报告学习增益、留存或考试通过率。

## 抽样证据

- 零基础：16科29章相关任务，原58道映射题及5道新参数迁移任务，修后回归14章改动/边界及原错题返回、自评。详见《大学生体验_零基础_2026-10-15.md》。
- 独立解题：16科31个不同章节、62道不同题与参数迁移，另做原失败流程回归。被告知答案的末期流程检查不计新增独立作答。详见《大学生体验_独立解题_2026-10-15.md》。
- 两人的题目有重叠，不把两数相加称为120道不同题。即使模拟角色能靠先验答出，只要当前讲义缺步骤，仍记教学阻碍。

## 实际修复

| 失败任务 | 修复 |
| --- | --- |
| 模电认得Q点却不会独立算 | 补固定偏置IB→IC→UCE、负载线端点、NPN结偏压回验，定义rbe与小信号增益及RE旁路前提 |
| 多级负载只说下降，反馈组态只给名称 | 补级间分压；输入串/并联与输出电压/电流取样分开讲，再组合四种阻抗变化 |
| 虚短虚断跳公式，迟滞无过程，纹波只看图 | 补运放节点电流列式、双阈值与中间区保留状态、峰间放电与纹波估算 |
| 二极管例子突然讲放大偏置，仪表题提前出现 | 改为LED串联限流与功耗；补测量安全，5道仪表/防护题移模电8 |
| 硬件题落操作系统章，中继器落网络层 | 3道硬件题移通识c02t05，中继器移net.media；共修9道题归属、2道计算题能力标签 |
| 文件与Office操作、组合电路和节点法缺首个执行任务 | 补同/跨卷拖放、快捷方式、系统操作、自定义序列、全加器/MUX及节点方程完整算例 |
| 讲义补齐但重点只剩概念 | 模电5张及相关数字、电路、通识短卡同步公式、边界和小例子；仍符合220字约束 |
| 选型表把未教实现的方法当已掌握 | DS8明确Trie、计数排序、二分答案、DP、回溯等为拓展识别，保留已教方法的选型任务 |
| 错题看讲义后返回换题 | 按浏览历史保存题号/范围/是否已答；返回及刷新保持原题解析，不重复计错，主动下一题才推进 |
| 到期复习直接露历史答案，80题限额挤掉当前题 | 新尝试先作答后看，复习队列保留刚答的当前题 |
| 手机自评按钮竖排、暗色字暗 | 修父grid状态优先级与跨列，三按钮横排不换行并采用主题字色；实测约121×44px |

删除缺少具体任务时的默认“综合应用·客观辨析/简答说明”等术语，保留优先级与具体任务。所有发现的阻断均经原路径复测后关闭；没有把一次扫描或答对率当作体验通过。

## 验证

- 两位分别重现原错题故障，修后返回、刷新均同题同解析；重点自评实际截图和点击复测通过。
- `scripts/verify_quiz_return.py`提供可重复的Playwright回归：手机/PC、7种练习路径、返回/刷新/主动下一题、空队列及100题复习队列，共16项无脚本错误。先构建dist，再使用可用的Playwright浏览器或传入`--browser-path`。
- 131章×手机/PC共262次目录定位通过；旧回忆记录、评级、首页任务刷新和离线阅读回归通过。
- 全量check_all通过。仍为16科、131章、264个知识点、2428题，标准答案与原有进度保持兼容。

## 残余边界

抽样任务内可以完成读、忆、练、回看闭环，不能称131章或2428题都重新验收。数据结构“堆、希尔、基数与排序选择”重点卡仍建议进一步拆分；标为拓展识别的方法没有完整实现教学；信号课仍需大学数学先修。代理模拟不能替代真人学习反馈。
