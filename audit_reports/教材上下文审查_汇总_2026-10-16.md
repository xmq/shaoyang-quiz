# 教材上下文审查与局部修复

本轮由计算机、电子、应用三个教材审查代理分别阅读16科134章讲义及385组重点，并检查268道关联题。审查重点是术语是否先解释、条件是否遗漏、操作能否接续、例题是否具备前置知识。独立复核使用模型代理，不是真实学生或盲测。

## 已修复

共修复23处局部问题：计算机组5处、电子组6处、应用组12处。代表性修复如下。

| 领域 | 缺漏与修复 |
| --- | --- |
| 数据结构 | BST原先从性质直接跳到AVL；补查找、插入、三类删除、根指针和后继右孩子接回，增加前后对照图及一道独立数值的过程题。 |
| 数据库 | 复合主键补业务唯一性条件；重复借阅采用独立事件编号。 |
| 操作系统 | 在硬链接例子前解释inode与目录项各自负责什么。 |
| C/Python | 补fgets接口、容量、返回值、EOF及无末尾换行的边界；随机实验改用已经教过的普通循环。 |
| 电子类 | 补对称三相条件、一阶低通原有相角、电流镜接线、三角波翻转过程、异或和共轭含义。 |
| 应用类 | 修正GB2312编码转换链，补IF参数、分类指标正类、STP端口过程、MVC、双if基路径等前置说明。 |

2526道既有题逐字段保持不变；新增1道BST删除过程题，发布题量2527。32份讲义及重点的章标题、重点标题、既有答案标记保持，385个知识点ID未变。
