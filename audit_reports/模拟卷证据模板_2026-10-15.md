# 模拟卷证据模板与 `exam-profiles.json` 数据草案

整理日期：2026-10-15  
适用范围：湖南事业单位计算机相关岗位的回忆版训练卷  
证据来源：`web/exam-sources.json`、`web/staging/hunan_exam_research.md`、`web/staging/hunan_recall_questions.json`

## 结论

仓库目前没有一套可核验的湖南计算机专业知识完整原卷，`complete_paper_count` 为 0，专业内部课程权重没有统计基础。因此：

- 可以按单次考生回忆建立长沙县2025、邵阳市直2026、湖南未明批次2026三种训练结构。
- 可以记录题型数量、已知客观/主观分值和明确回忆到的任务。
- `course_weights` 必须保持 `null`，不能根据题库题数、改编题数或零散考点推算网络、数据库等课程占比。
- 页面必须使用“回忆版训练结构”或“混合题型训练结构”，不能称为湖南统一卷、邵阳标准卷或完整真题卷。

## 建议字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `id` | string | 稳定模板ID，不随显示标题变化 |
| `title` | string | 学生可见名称，必须带“回忆版”或“训练结构” |
| `region` | string | 省、市县或“具体地区未注明” |
| `year` | integer | 回忆对应年份；无法确认考试年份时为 `null` |
| `exam_date` | string/null | 已与公告对应的考试日期，格式为 `YYYY-MM-DD` |
| `post` | string | 岗位名称；不明确时直接写明未核实 |
| `exam_subject` | string | 回忆针对的试卷或科目 |
| `evidence_level` | string | `A`官方完整卷；`B`官方事件与回忆可互证；`C`无法对应官方批次的具体回忆；`D`培训或转载线索 |
| `evidence_note` | string | 说明等级理由和资料缺口 |
| `sources` | array | 使用仓库考情台账中的来源ID，分别说明其能确认什么 |
| `total_score` | number/null | 试卷总分；回忆推断时必须在限制中说明 |
| `question_count` | number/null | 能由题型数量相加得到时填写；大题数量未知时为 `null` |
| `question_types` | array | 每种题型的题数、单题分、合计分和备注；未知值用 `null` |
| `objective_score` | number/null | 客观题合计分；仅在资料明确时填写 |
| `subjective_score` | number/null | 主观题合计分；仅在资料明确时填写 |
| `course_weights` | object/null | 课程内部权重；当前三套模板必须为 `null` |
| `observed_courses` | array | 只表示回忆中出现过，不表示权重或频率 |
| `observed_tasks` | array | 可定位到的主观任务或具体客观考点 |
| `use` | string | 允许如何生成训练卷 |
| `limits` | array | 不允许作出的结论和模板缺失信息 |

### 证据等级使用规则

- `A`：官方完整试卷、官方答案及可核对评分标准。当前湖南资料中没有A级计算机专业卷。
- `B`：招聘公告能确认考试事件、日期或科目，考生回忆与事件吻合，但没有完整原卷。
- `C`：回忆内容具体，但缺招聘单位、岗位代码、考试日期或官方事件对应关系。
- `D`：培训机构说明、商业题库标题、转载预览等，只用于发现可能题型，不单独生成地区模拟卷。

## 生成模拟卷时的强制规则

1. 选择模板只决定题型框架，不决定课程内部权重。
2. `course_weights` 为 `null` 时，抽题程序必须使用单独的教学蓝图，并在结果页显示“课程分布为训练配置，不是真题统计”。
3. `observed_courses` 只用于保证范围覆盖，不能自动平均分配，也不能按数组顺序赋权。
4. `observed_tasks` 中的任务可以设置为必选题型原型，但题目必须重新命制并保留来源说明。
5. 邵阳市直模板的客观区只能整体归一化为70分，不能猜测单选、多选和判断各题分值。
6. 长沙县模板的40分主观区题数未知，生成时应由训练配置决定数量，并明确这是训练拆分。
7. 湖南未明批次模板没有分值证据，只能按题数生成练习，不显示“还原分值”。
8. 后续若取得完整官方卷，应新建A级模板并保留当前回忆模板，不能静默覆盖历史证据。

## 尚缺资料

- 三种回忆对应的完整题面和评分标准。
- 邵阳市直2026回忆中缺失的第3道主观题，以及客观题5分差额的来源。
- 长沙县2025专业卷40分主观题的完整题数与各题分值。
- 湖南未明批次的招聘单位、岗位代码、考试日期和总分。
- 能支持网络、数据库、操作系统等课程内部比例的完整试卷样本。
