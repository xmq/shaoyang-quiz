# 普通本科深度重评

目标统一为普通大学本科课程的基础教学与常见期末任务：定义准确，能说清条件和参数，能走通典型过程，能完成常规计算、场景判断或简短程序。降低复杂证明和工程实现深度，不删除通用教材的正式知识主干。

本轮三个代理分别重读16科现有讲义与重点，并结合官方本科大纲、课程资料及正式教材目录复核。来源有全文、目录、官方检索片段及访问失败限制，不是每一条都读到了教材全文；也不把一所学校的课时安排当成全国唯一标准。各组原始记录保持独立。

## 逐科结论

表中列的是目前最需要处理的基础单元或常规过程，不等于对应整科、整章完全没教。详细分层与证据见三组报告和同名JSON。

| 课程 | 本科深度下的当前结论与待补 |
| --- | --- |
| 计算机组成原理 | 主干与多项常规题已有支撑；先行进位已有G/P和全加器关系，可补两位展开与数值核验，把“展开”这一步讲清。不是要求完整CPU工程。 |
| 操作系统原理 | 资源管理主干已有；多级反馈队列缺规则/轨迹，实时调度与死锁检测缺最小排程/等待图例。NUMA保留基础认识，不要求内核实现。 |

| 数据库技术 | SQL、设计、依赖、事务等主要任务已有；过程化SQL/游标补最小调用/遍历结构。仓库的事实/维度/粒度和非关系数据读写补低深度小例，不要求企业平台或多产品实现。 |

| 信号与系统 | 卷积、Fourier/Laplace、Z/DTFT、FIR/IIR及RC状态/反馈已有；DFT/IDFT、频点、短正逆例和圆周卷积仍缺。非零初值差分、相关/Parseval补基础例；FFT保留思想和小步认识，完整实现不设为门槛。 |

| 多媒体技术 | 表示、容量、压缩与作品流程已有基础支撑；三维概念细分保留认识补强/待核，不把完整光照数学、编码器、MPEG码流作为共同最低门槛。 |

## 修正旧清单

1. **缺漏与深度边界分开。** “没有完整数据库内核、NUMA源码、FPGA工程、SDN配置、专业编码器”不再当作普通本科统一缺口；基本概念与必要流程仍保留。
2. **DFT与FFT不再打包验收。** 选定信号教材有离散变换主线，因此DFT基础、频点和短算例保留；完整多级蝶形、位倒序及通用FFT程序是更深实现。[所选教材目录及两门课分工的证据见电子组报告](本科深度重评_电子组_2026-10-19.md)。
3. **修正过时的“整章无”。** 现有讲义已经补有Z/DTFT、FIR/IIR、反馈/RC状态、SAR步骤等，不能继续引用早期快照认定整域没教。
4. **不把更多变体无限升级为缺口。** 数字时序已有可执行代表例，再加非2幂或更多状态的题是练习加强；已有RC状态例，不能只因没有更高维示例就称状态域未教。报告中相关建议保留，汇总不列新硬门槛。
5. **基本教学缺漏没有撤销。** 二阶RLC、B树删除、反馈队列、CMM/Jackson等仍须补最小可学单元，不能只加标题。CMM和Jackson均可在[所选《软件工程导论》第6版正式目录](https://www.tup.com.cn/booksCenter/bookcatalog?id=05016406)定位，具体本科任务与不同术语边界在应用组记录。

## 维护记录调整

- `course-guide.json`写入统一本科深度标准，去掉按岗位把部分课程缩成只辨认的旧表述，以及网络“26个知识点”的过时固定数和仅一步计算的限制。
- `textbook-coverage.json`的当前待补列表改用本轮基础任务，旧条目留档；“认识补强”“本轮无需”“证据待核”独立记录。整书外部范围验收与本科深度是两个维度，没有把16科批量标为完整。
- 原基础课教材链接经核实为医学类用书；改以[龚沛曾、杨志强《大学计算机》第7版通用教材目录](https://xuanshu.hep.com.cn/front/book/findBookDetails?bookId=59cf88c8ba9eb884cf8238f8)对照基础主干。办公、数据库、网络及程序的承接课程和稳定章ID已在维护记录中明确，不声称基础讲义本身重教了全部独立课程。
- 本轮没有新增或删除讲义、重点、题目和知识点ID，也没有改页面或学习记录。清单是后续待补任务，不是这些内容已经修复的证明。
