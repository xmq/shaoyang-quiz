# 通信原理与高频电子线路：重点与易错

## 第1章 通信系统概论
### 通信链路与传输方式

- 🔴 **核心知识**：通信链为信源→发送设备→信道→接收设备→信宿，噪声可由传输及接收环节引入。
- 🔵 **方法与例题**：广播为单工；普通对讲机为半双工；双方可同时讲话的电话为全双工。
- ⚫ **易混易错**：半双工允许双向但不能同时；模拟/数字、基带/带通是另一组分类依据。

## 第2章 信号、信道与噪声
### 码元速率、信息速率与可靠性

- 🔴 **核心知识**：码元速率RB单位Bd；M种等概且独立符号码元含log₂M bit，Rb=RB log₂M。
- 🔵 **方法与例题**：四进制1200 Bd得到2400 bit/s；误码率=错误比特数/总比特数，可靠性不等于速率。
- ⚫ **易混易错**：编码冗余与帧开销会降低业务净率；不同概率符号平均信息量不一定等于log₂M。

### 香农容量与奈奎斯特速率

- 🔴 **核心知识**：AWGN带限信道C=B log₂(1+S/N)；理想低通无码间串扰RB≤2B，M进制Rb≤2B log₂M。
- 🔵 **方法与例题**：B=1 MHz、S/N=3得C=2 Mbit/s；SNR=20 dB先转100再代入。
- ⚫ **易混易错**：B取Hz，信噪比用线性功率比；两种公式约束不同，也都不是模拟采样定理。

## 第3章 模拟信号数字化与调制
### 抽样、量化与PCM码率

- 🔴 **核心知识**：带限最高fH，理想采样通常取fs>2fH；PCM无帧及纠错开销Rb=fs×每样位数×通道数。
- 🔵 **方法与例题**：8 kHz、每样8 bit、单声道得到64 kbit/s；2位0～4 V每档1 V，2.3 V编码10。
- ⚫ **易混易错**：采样前需抗混叠；量化会有幅值误差，理论奈奎斯特边界不等于任意临界采样都能恢复。

### 模拟与数字调制选择

- 🔴 **核心知识**：AM/FM/PM分别改变载波幅度/瞬时频率/相位；ASK/FSK/PSK按离散状态载信息，QAM改变I/Q组合。
- 🔵 **方法与例题**：普通AM不过调可包络检波，DSB-SC通常相干解调；FM卡森带宽约2(Δf+fm)。
- ⚫ **易混易错**：FM抗幅度干扰有前提且常占更多带宽；数字调制的物理波形仍是连续电磁量。

### 复用、线路编码与同步

- 🔴 **核心知识**：FDM分频带、TDM分时隙、WDM分光波长、CDM分码；线路编码要兼顾频谱与时钟提取。
- 🔵 **方法与例题**：NRZ连续相同比特可无跳变；曼彻斯特每位中间必跳变，方向按标准约定。
- ⚫ **易混易错**：复用资源与调制类型不同；物理同步保证边界识别，不自动保证应用业务不重复。

### 同步TDM帧率与开销

- 🔴 **核心知识**：每帧每路取一个样值时，帧率等于每路采样率，线路码率=帧率×每帧总位数。
- 🔵 **方法与例题**：4路8 kHz、每样8 bit：每帧32 bit；另加1同步位，8000×33=264 kbit/s。
- ⚫ **易混易错**：32 k样值/秒是全部支路样值总数，不是本帧结构帧率；每时隙取1 bit须重算。

## 第4章 传输媒质与电磁波谱
### 介质、传播与频谱位置

- 🔴 **核心知识**：有线含双绞、同轴、光纤；无线传播有地波、天波、视距等，传播特性随频段与环境变化。
- 🔵 **方法与例题**：λ=v/f；真空300 MHz对应1 m；1310/1550 nm光纤窗口属于近红外。
- ⚫ **易混易错**：微波属于无线电波；1550 nm低损耗、1310 nm低色散须结合标准单模等光纤类型。

## 第5章 数字调制与移动通信
### 数字调制与移动代际

- 🔴 **核心知识**：BPSK两相位1 bit/符号，QPSK四相位2 bit/符号；蜂窝代际还涉及接口、架构与业务能力。
- 🔵 **方法与例题**：相同1200 Bd下BPSK为1200 bit/s、QPSK为2400 bit/s，均未计编码帧开销。
- ⚫ **易混易错**：高阶星座点密通常需更高信噪比；Wi-Fi不属于某一蜂窝代际，5G不只指高速下载。

## 第6章 高频小信号、功率放大与混频
### 调谐放大、混频与超外差

- 🔴 **核心知识**：超外差依次射频选频放大→混频→固定中频放大→解调；混频保留原调制而搬移中心频率。
- 🔵 **方法与例题**：fIF=|fLO−fs|；本振110 MHz、信号100 MHz得10 MHz中频，120 MHz也会产生同一中频镜像。
- ⚫ **易混易错**：镜像需射频预选抑制；固定中频便于选频放大，但不能将混频当作恢复基带的解调。

### 振荡器、反馈与锁相环

- 🔴 **核心知识**：振荡器由选频、放大、正反馈及稳幅等构成；PLL由鉴相器、环路滤波器、VCO组成反馈环。
- 🔵 **方法与例题**：LC谐振f0=1/(2π√LC)；分频PLL锁定时fout=Nfref，100 kHz×900=90 MHz。
- ⚫ **易混易错**：起振与稳幅条件不同；正反馈不凭空供能，VCO调节范围与环路稳定性均有限。

### 锁相环误差反馈过程

- 🔴 **核心知识**：鉴相检测参考与反馈相位差，滤波形成控制量，VCO改频率、累积改变相位，负反馈压小误差。
- 🔵 **方法与例题**：参考突然变快→相位误差出现→控制VCO提高频率→追上后误差趋稳；实际方向依鉴相及VCO极性。
- ⚫ **易混易错**：捕获是从失锁进入锁定，保持是锁定后的跟踪；超出范围可失锁，不能预设永远同频。

## 第7章 信源编码与信道编码
### 信源编码与信道编码

- 🔴 **核心知识**：信源编码去除统计冗余以压缩；信道编码增加受控冗余以检错纠错。
- 🔵 **方法与例题**：语音压缩后加入纠错码，两者可串联；熵给无损平均码长的理论约束而非每符号固定码长。
- ⚫ **易混易错**：压缩率高不代表抗噪声强；有损压缩与无损编码对恢复的要求不同。

### 奇偶校验、CRC与ARQ

- 🔴 **核心知识**：奇偶检奇数位错；CRC用模2余数检错；ARQ用确认、序号、超时、重传恢复传输。
- 🔵 **方法与例题**：数据1101、生成1011补3零做模2除法余001，发送1101001。
- ⚫ **易混易错**：余数0仍可能漏检；检错不等于定位纠错，重传没有序号可能重复交付。

### 离散信源熵的计算

- 🔴 **核心知识**：H=−Σpi log₂pi，单位bit/符号；等概率M符号为log₂M，概率0项按极限计0。
- 🔵 **方法与例题**：概率1/2、1/4、1/4，三项各贡献0.5，H=1.5；码0、10、11平均码长也为1.5。
- ⚫ **易混易错**：平均1.5 bit不表示每次能发送半位；有记忆信源须进一步考虑条件统计。

### CRC模2除法与余数

- 🔴 **核心知识**：r为生成多项式次数，发送数据后补r个0，以异或长除求r位余数，再把余数接原数据。
- 🔵 **方法与例题**：1101000依次异或1011000、0101100、0010110、0001011，余0000001，即001。
- ⚫ **易混易错**：模2减法不借位；余数前导0须保留r位；接收端用同一生成规则检验。

### ARQ确认、序号与超时

- 🔴 **核心知识**：停等ARQ一次只等一帧确认；超时触发重传，序号让接收端识别重复帧。
- 🔵 **方法与例题**：帧0已交付但ACK丢失，超时重发0；接收端只重回ACK，不再重复交付，然后发送端推进编号。
- ⚫ **易混易错**：确认也会丢失；校验正确并不能证明这是一帧新数据，迟到帧还需协议约束。

## 第8章 基带传输、同步与眼图
### 码间串扰与同步层次

- 🔴 **核心知识**：ISI是其他码元在当前抽样点留下干扰；归一化整体脉冲需p(0)=1、p(kT)=0（k非0）。
- 🔵 **方法与例题**：升余弦单边带宽B=(1+α)Rs/2；Rs=2000 Bd、α=0.5，B=1500 Hz。
- ⚫ **易混易错**：无码间串扰不要求所有时刻波形不重叠；位、帧、载波同步解决不同基准问题。

### 眼图判读与链路定位

- 🔴 **核心知识**：眼高反映幅度判决余量，眼宽反映定时余量；需相同码元速率、时基和幅度尺度下比较。
- 🔵 **方法与例题**：交叉点水平散开优先查定时抖动，轨迹变厚可查噪声；再配合时钟与分段波形确认。
- ⚫ **易混易错**：眼图闭合不能唯一指认某器件；带宽不足、ISI和噪声也可能同时存在。

## 第9章 光纤通信与链路分析
### 光纤链路、衰减与色散

- 🔴 **核心知识**：链路为电发送→光源/调制器→光纤→光检测→电接收；衰减降低功率，色散展宽脉冲。
- 🔵 **方法与例题**：功率不足先查光源、接头、弯曲；功率正常而眼图闭合，再查色散、带宽和同步。
- ⚫ **易混易错**：单模仍有色度色散；满足功率预算不代表满足全部速率距离条件。

### 链路预算与测试工具

- 🔴 **核心知识**：光功率计测功率；稳定光源配功率计测插入损耗；OTDR观察反射与后向散射定位。
- 🔵 **方法与例题**：OTDR距离L≈vt/2；预算按发射功率加增益、减实际损耗，再与灵敏度及过载值比较。
- ⚫ **易混易错**：OTDR有盲区，须结合链路资料；检修不可直视可能有光的端面。

### dB链路预算与余量

- 🔴 **核心知识**：dBm为相对1 mW绝对功率，dB为功率比；接收dBm=发射dBm+增益dB−损耗dB。
- 🔵 **方法与例题**：0 dBm发射、实际损耗7 dB得−7 dBm；灵敏度−12 dBm原余量5 dB，预留1 dB后可用4 dB。
- ⚫ **易混易错**：预留余量不改变当前物理功率；0 dBm不是零功率，两个dBm不能直接当增益相加。
