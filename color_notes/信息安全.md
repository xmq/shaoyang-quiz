# 信息安全：重点与易错

## 第1章 信息安全概论

### CIA安全目标
- 🔴 **核心知识**：机密性防泄露，完整性防篡改并要求可发现，可用性保障授权使用；一次事件可同时损害多个目标。
- 🔵 **方法与例题**：先写业务任务，再判断“谁看见、内容是否可信、服务能否使用”；偷看档案、修改金额、打停网站分别对应C、I、A。
- ⚫ **易混易错**：加密不能自动保证可用性；断网可能降低部分威胁，也可能直接破坏业务。

### 风险链与安全原则
- 🔴 **核心知识**：风险由资产、威胁、脆弱性、可能性和影响共同决定；最小权限、默认拒绝、职责分离与纵深防御用于降低风险。
- 🔵 **方法与例题**：按“资产→威胁→弱点→影响”写场景，例如成绩库、盗号者、弱口令、成绩泄露和篡改。
- ⚫ **易混易错**：有漏洞不等于已被攻击，无告警不等于无风险；最小权限也不能少到无法完成授权业务。

## 第2章 安全管理与风险管理

### 控制分类与风险处置
- 🔴 **核心知识**：管理、技术、物理控制要覆盖预防、检测、响应和恢复；风险可规避、降低、转移或接受。
- 🔵 **方法与例题**：先识别现有控制和剩余风险，再写责任人、验证方法和复查时机；外包可转移部分损失，不能转走全部责任。
- ⚫ **易混易错**：买设备不是完成治理；只有预防没有检测和恢复，方案仍不完整。

### 账号口令与等级保护
- 🔴 **核心知识**：账号经历申请、授权、复核、变更和注销；口令使用独立盐和专用慢散列；等保按影响定级并持续建设、测评和整改。
- 🔵 **方法与例题**：转岗时同时查角色、直接授权、令牌和密钥；盐抵抗预计算，计算成本抵抗批量猜测。
- ⚫ **易混易错**：盐不必保密，也不能替代MFA和限速；等保不是一次认证或设备清单。

## 第3章 恶意代码与社会工程

### 恶意代码传播机制
- 🔴 **核心知识**：病毒依附宿主，蠕虫网络自传播，木马伪装诱导；勒索描述目的，可借多种机制传播。
- 🔵 **方法与例题**：见“无需宿主、自动扫描传播”优先判蠕虫；见“伪装工具诱导安装”优先判木马。
- ⚫ **易混易错**：勒索软件和木马、蠕虫不是互斥分类；杀毒软件存在误报与漏报。

### 社会工程与感染处置
- 🔴 **核心知识**：钓鱼利用紧迫、权威和信任诱导泄密；处置遵循停止操作、独立核验、上报留证、控制账号与主机影响。
- 🔵 **方法与例题**：已输入验证码时撤销会话、重置凭据并查日志；文件被加密时先隔离留证，再根除和恢复。
- ⚫ **易混易错**：熟人头像、发件地址和HTTPS都不能单独证明可信；直接格式化会破坏证据。

## 第4章 身份认证与访问控制

### 认证因素与会话
- 🔴 **核心知识**：认证确认身份，授权决定权限，审计记录行为；MFA组合知识、持有物或生物特征等不同因素。
- 🔵 **方法与例题**：两个口令仍是一类因素；认证后还要保护会话令牌、退出、撤销和账号恢复流程。
- ⚫ **易混易错**：登录成功不等于拥有全部权限；多步骤也不必然是多因素。

### 访问控制模型与复核
- 🔴 **核心知识**：DAC由所有者授权，MAC按标签强制控制，RBAC按岗位角色授权，ABAC按主体、资源、操作和环境属性决策。
- 🔵 **方法与例题**：先列主体、资源、操作和条件，再按最小权限分配；高风险任务加入职责分离与双人审批。
- ⚫ **易混易错**：复核要同时看角色、直接授权、临时权限和闲置账号，不能只查用户所属角色。

## 第5章 密码学基础

### 对称、非对称与混合加密
- 🔴 **核心知识**：对称加密快但共享密钥难分发；非对称机制便于协商、认证和签名但开销大，实际通信常混合使用。
- 🔵 **方法与例题**：先用公钥机制验证身份并建立随机会话密钥，再用对称算法加密大量数据。
- ⚫ **易混易错**：公钥可公开，私钥与会话密钥要保护；算法公开不等于系统不安全。

### 哈希、MAC、签名与证书
- 🔴 **核心知识**：哈希生成摘要；MAC用共享密钥验证来源与完整性；签名私钥生成、公钥验证；证书绑定身份和公钥。
- 🔵 **方法与例题**：验签同时检查消息摘要；验证证书要看信任链、名称、有效期和撤销状态。
- ⚫ **易混易错**：哈希不可解密，签名不自动保密；证书有效也不证明网站内容和交易可信。

## 第6章 网络安全

### 网络分区与边界防护
- 🔴 **核心知识**：互联网、DMZ、应用区和数据区按最小开放分层；防火墙控制，IDS检测，IPS可在线阻断。
- 🔵 **方法与例题**：规则写清源、目的、端口、方向和条件；数据库只允许应用服务器访问，比向办公网开放更合理。
- ⚫ **易混易错**：DMZ不是天然安全区，允许端口仍可能携带攻击；自动阻断还要评估误伤。

### 网络攻击与排障
- 🔴 **核心知识**：DDoS耗尽资源，中间人介入通信，欺骗伪造映射；VPN/TLS保护通道但不修复端点和应用漏洞。
- 🔵 **方法与例题**：服务变慢先核对容量、配置、流量和日志，再判断攻击并选择限流、隔离或清洗。
- ⚫ **易混易错**：异常现象不是攻击结论；HTTPS网站仍可能存在注入、越权和业务漏洞。

## 第7章 系统、应用与数据安全

### 主机与应用防护
- 🔴 **核心知识**：补丁、最小服务和权限缩小攻击面；参数化查询防SQL注入，上下文输出编码防XSS，关键请求仍需认证授权。
- 🔵 **方法与例题**：输入作为参数绑定而非拼SQL；输出到HTML、属性、脚本和URL时分别采用对应编码。
- ⚫ **易混易错**：客户端校验可绕过；参数化查询不能防全部应用漏洞，HTTPS也不能防越权。

### 备份、RPO与RTO
- 🔴 **核心知识**：3-2-1备份配合离线或不可变副本；RPO限制可丢数据量，RTO限制恢复时间。
- 🔵 **方法与例题**：“最多丢15分钟、2小时恢复”分别对应RPO 15分钟、RTO 2小时，并要用恢复演练验证。
- ⚫ **易混易错**：RAID、镜像和同步复制会同步误删，不能代替独立备份；备份成功不等于恢复成功。

### 事件响应闭环
- 🔴 **核心知识**：准备→发现报告→分析→遏制→根除→恢复→复盘；日志要有时间、主体、来源、操作、对象和结果。
- 🔵 **方法与例题**：隔离主机属遏制，修补入口和撤销凭据属根除，从可信备份上线属恢复。
- ⚫ **易混易错**：遏制不是根除；未确认范围时随意关机、格式化和删日志会破坏证据。

## 第8章 隐私保护、法律与职业责任

### 最小必要与重新识别
- 🔴 **核心知识**：个人信息按明确目的最小收集、最小访问和限期保存；去标识化仍可能被准标识符组合重新识别。
- 🔵 **方法与例题**：统计只需汇总时不保留姓名、学号等明细；检查年龄、院系、地区和时间组合是否指向少数人。
- ⚫ **易混易错**：取得同意不代表无限使用，删除姓名不等于匿名化，公开可见也不等于可任意商用。

### 授权边界与规则核验
- 🔴 **核心知识**：技术上能访问不等于有权访问；扫描、复制、查询和测试都需要明确授权、范围、时间和责任。
- 🔵 **方法与例题**：遇到具体条款、处罚、期限和适用范围时查现行官方文本及单位制度，并记录依据版本。
- ⚫ **易混易错**：学习或测试目的不能替代授权；合规是底线，也不能代替技术与管理风险控制。
