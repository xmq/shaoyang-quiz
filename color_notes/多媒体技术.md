# 多媒体技术：重点与易错
## 第1章 多媒体技术概论
### 多媒体特征与系统组成
- 🔴 **核心知识**：多媒体把文本、图形图像、音频、动画和视频数字化并集成处理；多样性、集成性、交互性和实时性描述不同能力。
- 🔵 **方法与例题**：可选择章节并获得响应的课程同时体现集成与交互；系统还需采集、处理、存储、输出和通信软硬件。
- ⚫ **易混易错**：媒体种类多不等于交互强；同一设备可兼具输入输出，媒体分类应看主要作用而非设备名称。

### 超文本与超媒体
- 🔴 **核心知识**：超文本用链接组织非线性文本节点，超媒体把节点扩展到图片、音频和视频；关键是可沿关系选择路径。
- 🔵 **方法与例题**：点击知识点打开对应视频或图示属于超媒体；只按固定顺序播放的一段视频不必然具有这种链接结构。
- ⚫ **易混易错**：超媒体不是媒体种类的简单堆叠；是否边收边播属于流媒体的传送方式，应与节点链接结构分别判断。

## 第2章 多媒体计算机系统与数字化
### 采样、量化与编码
- 🔴 **核心知识**：采样离散时间，量化离散幅值，编码把等级写成数字；n位量化有2^n级，带限信号采样率理论上至少为最高频率两倍。
- 🔵 **方法与例题**：18kHz音频理论最低36kHz，实际需滤波余量；16bit提供65536级，采样率和位数解决不同维度。
- ⚫ **易混易错**：临界两倍不无条件保证恢复；混叠发生后不能靠提高量化位数补救，提高采样率也不能恢复采集前丢失信息。

### 容量、码率与单位
- 🔴 **核心知识**：位图容量=像素数×位深÷8，PCM容量=采样率×位数×通道×时间÷8，码率文件容量=总码率×时间÷8。
- 🔵 **方法与例题**：2Mbit/s持续60秒约15MB；先统一Hz、bit、秒和Byte，已给总码率时不重复乘分辨率和帧率。
- ⚫ **易混易错**：1000与1024口径要声明；文件头、索引、容器和可变码率会让实际文件偏离理论值。

## 第3章 数字图形与图像
### 位图、矢量与分辨率
- 🔴 **核心知识**：位图由像素构成，适合照片；矢量图由几何对象描述，适合标志线条。分辨率是像素规模，色深决定每像素可表示状态。
- 🔵 **方法与例题**：可缩放徽标优先SVG，截图优先位图；800×600、24bit未压缩约1440000B。
- ⚫ **易混易错**：矢量文件不保证一定更小；PPI与DPI使用场景不同，透明通道、调色板和行填充会改变容量。

### 颜色模型与交付
- 🔴 **核心知识**：RGB用于发光显示，CMYK用于印刷，HSV便于调色，YCbCr分离亮度与色度；不同模型色域和成色方式不同。
- 🔵 **方法与例题**：屏幕稿交付印刷前检查CMYK转换、配置文件、黑色文字和打样，不能假设屏幕颜色原样复制。
- ⚫ **易混易错**：RGB三原色不是颜料红黄蓝；颜色模式转换可能丢失色域，改扩展名不会自动完成正确色彩管理。

### 格式、图层与蒙版
- 🔴 **核心知识**：JPEG适合照片有损分发，PNG无损且支持透明，GIF支持有限色动画，SVG可缩放，PSD保留图层编辑结构。
- 🔵 **方法与例题**：发布网页图标可用PNG/SVG，反复编辑先保留PSD等源文件；蒙版控制显示而不直接删除原像素。
- ⚫ **易混易错**：另存JPEG不会提高原图质量；图层、选区、蒙版和路径职责不同，扁平化后可能失去编辑能力。

## 第4章 数字音频
### 声音采集与PCM
- 🔴 **核心知识**：声波经麦克风、滤波、ADC采样量化编码成为数字音频；播放时解码并经DAC、扬声器返回声波。
- 🔵 **方法与例题**：44.1kHz、16bit、双声道1秒PCM约176.4kB；参数提高通常增大原始码率，但音质还受设备和编码影响。
- ⚫ **易混易错**：数字数据仍需电、光或无线物理信号承载；压缩音频不能直接套PCM容量公式。

### 波形音频、MIDI与格式
- 🔴 **核心知识**：波形音频记录采样值，可保存人声环境声；MIDI记录音符和控制事件。WAV是容器，MP3/AAC有损，FLAC无损。
- 🔵 **方法与例题**：录制讲话选波形音频；乐器控制和重新编配可用MIDI。播放效果还取决于音源与解码支持。
- ⚫ **易混易错**：MIDI不是麦克风录音；WAV不等于必然未压缩，扩展名不能说明全部内部编码参数。

## 第5章 动画与数字视频
### 动画时间轴与帧率
- 🔴 **核心知识**：帧、帧率、时间轴和关键帧共同描述动画；逐帧逐张制作，运动补间生成位置变化，形状补间生成矢量形变。
- 🔵 **方法与例题**：10秒、25帧/秒共250帧；控制精细变化可逐帧，规则位移旋转可用运动补间。
- ⚫ **易混易错**：帧率更高不自动代表内容更清晰；位图形变与矢量形状补间条件不同，关键帧不等于每一帧。

### 视频参数、编码器与容器
- 🔴 **核心知识**：分辨率、帧率、位深和码率影响视频；H.264/H.265是编码方式，MP4/MKV/MOV是封装音视频字幕的容器。
- 🔵 **方法与例题**：设备能打开MP4但仍可能无法解码内部轨道；同分辨率视频因编码、码率和内容复杂度不同而大小画质不同。
- ⚫ **易混易错**：扩展名不能唯一确定编码器；给出压缩总码率后不再重复乘像素、色深和帧率。

### 流媒体与自适应播放
- 🔴 **核心知识**：流媒体边接收边播放，直播更关注低时延，点播可使用更大缓冲；自适应码率根据网络切换清晰度。
- 🔵 **方法与例题**：网络波动时播放器降低码率可减少停顿；排障同时观察吞吐、缓冲、时延、抖动和设备解码能力。
- ⚫ **易混易错**：标称带宽不等于稳定有效吞吐；降低分辨率只是降低码率的一种手段，缓冲变大也会增加启动或直播延迟。

## 第6章 多媒体数据压缩
### 无损、有损与冗余
- 🔴 **核心知识**：无损可恢复原数据，有损舍弃部分信息换体积；压缩利用空间、时间、统计或感知冗余。
- 🔵 **方法与例题**：程序、文本和编辑母版需精确恢复；照片音视频分发可按质量目标有损压缩，并保留可编辑源文件。
- ⚫ **易混易错**：无损不保证任何输入都变小；转存无损不能找回此前损失，反复有损保存会累积退化。

### 压缩比与格式选择
- 🔴 **核心知识**：压缩比=原始量÷压后量，节省率=(原始量−压后量)÷原始量；选择格式还要看透明、动画、编辑和兼容需求。
- 🔵 **方法与例题**：896kB压到128kB，压缩比7:1，节省率约85.7%；透明图标可选PNG，照片发布可选JPEG。
- ⚫ **易混易错**：压缩比与节省率不是同一数值；文件格式可能同时支持多种编码，不能只凭扩展名断言全部参数。

## 第7章 多媒体作品设计与应用
### 需求、脚本与素材组织
- 🔴 **核心知识**：制作依次考虑受众目标、内容结构脚本、素材采集、编辑集成、测试发布；媒体形式服从信息和设备条件。
- 🔵 **方法与例题**：手机教学视频先写步骤脚本和字幕，再按小屏、耳机和移动网络选择画面、声音与码率。
- ⚫ **易混易错**：先堆素材再找主题会造成结构混乱；素材可访问不代表拥有使用授权，隐私信息也需处理。

### 图层蒙版、测试与交付
- 🔴 **核心知识**：图层分离对象，蒙版非破坏控制显示；发布前检查导航、同步、字幕、色彩、编码、性能、版权和兼容性。
- 🔵 **方法与例题**：保留分层源文件便于修改，另导出目标平台版本，并在真实手机、浏览器和网络条件下测试。
- ⚫ **易混易错**：本机可播放不保证其他平台可用；过时软件菜单不是通用原理，交付副本不能替代源文件和素材授权记录。
