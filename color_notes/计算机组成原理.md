# 计算机组成原理：重点与易错

## 第1章 计算机系统概论
### 存储程序与系统组成
- 🔴 **核心知识**：冯·诺依曼机把指令和数据存入存储器，由运算器、控制器、存储器、输入和输出部件协同工作；CPU由运算器、控制器和寄存器等组成。
- 🔵 **方法与例题**：沿“输入程序和数据→存入主存→CPU取指执行→写回或输出”解释运行过程；判断部件时先看它负责运算、控制、保存还是交互。
- ⚫ **易混易错**：体系结构描述程序员可见属性，组成关注实现方式；CPU不包含全部主存和外设，主机、CPU与完整计算机系统范围不同。

### 性能指标与时间计算
- 🔴 **核心知识**：CPU时间=指令数×平均CPI÷时钟频率；时钟周期是频率倒数，吞吐率表示单位时间完成量，响应时间表示单个任务完成时长。
- 🔵 **方法与例题**：100万条指令、CPI为2、主频1GHz时，CPU时间为2毫秒；比较机器时必须同时核对指令数、CPI和频率。
- ⚫ **易混易错**：主频高不保证程序快，MIPS也不能脱离指令集比较；CPU时间通常不含I/O等待，bit与Byte、MHz与GHz先统一单位。

## 第2章 数据表示与运算
### 数制、编码与位权
- 🔴 **核心知识**：二、八、十六进制按位权表示数，二进制与十六进制可每4位互换；BCD编码十进制数字，ASCII和Unicode处理字符。
- 🔵 **方法与例题**：二进制101101按位权得45，也可分组为2D十六进制；小数转换按2反复乘取整，并明确允许的精度。
- ⚫ **易混易错**：数值45、字符“45”和BCD 45编码不同；进制下标不是数的一部分，补位方向和小数点位置不能改变。

### 原码、反码、补码与溢出
- 🔴 **核心知识**：正数三种机器码相同，负数补码由原码数值位取反加1；n位补码范围为−2^(n−1)到2^(n−1)−1，加减统一用补码完成。
- 🔵 **方法与例题**：8位−5为11111011；同号数相加得到异号结果说明有符号溢出，127+1得到10000000即溢出。
- ⚫ **易混易错**：最高位进位不能单独判断有符号溢出；补码最小负数没有对应正数，符号扩展要复制符号位而非补0。

### 定点与浮点表示
- 🔴 **核心知识**：定点数的小数点位置固定，浮点数由符号、阶码和尾数组成；规格化通过调整阶码和尾数保持数值，范围主要由阶码决定。
- 🔵 **方法与例题**：单精度按1/8/23位拆分，正常数实际阶=E−127并补隐藏1；如0｜10000001｜010…=1.25×2²=5。
- ⚫ **易混易错**：浮点范围大不等于所有数精确，尾数位决定精度；对阶通常让小阶向大阶移动，会丢失低位有效数字。

## 第3章 指令系统与CPU
### CPU部件与指令周期
- 🔴 **核心知识**：PC保存下一条指令地址，IR保存当前指令，MAR/MDR参与访存，ALU运算，控制器按时序发出控制信号；指令经历取指、译码、执行和写回。
- 🔵 **方法与例题**：取指可描述为PC送MAR、主存读入MDR再送IR、PC更新；执行阶段再按操作数来源访问寄存器或存储器。
- ⚫ **易混易错**：PC通常指向下一条而非当前指令内容；指令周期可能含多个机器周期，进入中断也不等于正在执行普通函数调用。

### 指令、寻址与RISC/CISC
- 🔴 **核心知识**：指令含操作码和地址字段；立即、直接、间接、寄存器、基址、变址和相对寻址用不同路径形成操作数或有效地址。
- 🔵 **方法与例题**：基址1000、位移20得有效地址1020；相对寻址用PC加位移，适合分支；比较时同时写访存次数和地址计算过程。
- ⚫ **易混易错**：立即数是操作数本身，直接地址才指向操作数；RISC/CISC是设计取向，不能简化成“谁一定更快”。

## 第4章 存储器
### 存储层次与局部性
- 🔴 **核心知识**：寄存器、Cache、主存、外存按速度、容量和成本分层；时间局部性是近期访问可能再访问，空间局部性是邻近地址可能被访问。
- 🔵 **方法与例题**：循环重复访问数组兼有时间和空间局部性；判断层次作用时看它是在缩短CPU等待、扩充容量还是提供持久保存。
- ⚫ **易混易错**：Cache和主存通常易失，外存速度慢但持久；层次对程序呈现近似大容量低成本存储，并不让所有访问一样快。

### 主存容量、编址与芯片扩展
- 🔴 **核心知识**：n根地址线可选2^n个编址单元，容量=单元数×每单元位数；位扩展增加字长，字扩展增加单元数，常用片选区分芯片。
- 🔵 **方法与例题**：16位地址、按字节编址容量为64KiB；用8K×8芯片组成32K×16需字扩4倍、位扩2倍，共8片。
- ⚫ **易混易错**：按字编址还要乘字长；地址线数量与数据线宽度职责不同，K在存储容量题常按1024解释。

### Cache映射与平均访存时间
- 🔴 **核心知识**：直接映射每块只能去固定行，全相联可去任意行，组相联在指定组内选择；地址拆成标记、组索引和块内偏移。
- 🔵 **方法与例题**：组数=容量÷(块×路数)，偏移/索引取log₂，标记用总位数减去二者；AMAT=命中时间+失效率×额外代价。
- ⚫ **易混易错**：未命中代价是否已含首次查Cache必须看题意；命中率高仍可能被大缺失代价拖慢，写策略和替换策略也会影响行为。

## 第5章 控制单元与指令流水
### 流水线与相关冲突
- 🔴 **核心知识**：流水线让多条指令的不同阶段重叠，提高吞吐率；结构冲突争用部件，数据相关等待结果，控制相关来自分支改变取指方向。
- 🔵 **方法与例题**：理想k段处理n条需k+n−1拍，5段10条为14拍；先画时空图，再加入停顿、转发或分支罚时计算总周期。
- ⚫ **易混易错**：流水线通常不把单条指令延迟缩短k倍；时钟周期受最慢阶段和流水寄存器开销限制，理想公式不能忽略题目给出的停顿。

## 第6章 系统总线与输入输出
### 总线结构与带宽
- 🔴 **核心知识**：地址总线选择对象，数据总线传送内容，控制总线携带读写和时序信号；总线带宽由数据宽度、频率和每周期传输次数共同决定。
- 🔵 **方法与例题**：32位总线每周期传1次、100MHz时理论带宽为4B×100M=400MB/s；若双倍传输再乘2。
- ⚫ **易混易错**：地址总线宽度决定可寻址范围而非一次数据量；理论带宽不含仲裁、等待和协议开销，MB/s与Mb/s相差8倍。

### I/O控制、中断与DMA
- 🔴 **核心知识**：程序查询让CPU反复检查设备，中断由设备就绪后通知CPU，DMA由控制器成块搬运内存与设备数据；三者CPU介入频度依次降低。
- 🔵 **方法与例题**：低速偶发键盘适合中断，大块磁盘传输适合DMA；分析中断依次写请求、响应、保存现场、执行服务和恢复返回。
- ⚫ **易混易错**：DMA仍需CPU初始化和结束处理，也会与CPU竞争总线；中断向量用于定位服务程序，不等于设备数据本身。

## 第7章 存储系统扩展
### 虚拟地址、页表与TLB
- 🔴 **核心知识**：MMU用页表把虚拟页号映射为物理页框号，页内偏移不变；TLB缓存近期页表项，缺页则需操作系统从外存调入页面。
- 🔵 **方法与例题**：4KiB页取低12位偏移，页表用页框替换页号；串行模型EAT=h(ε+T)+(1−h)(ε+2T)，缺页另算。
- ⚫ **易混易错**：Cache未命中、TLB未命中和缺页属于不同层次；虚拟地址宽度不必等于物理地址宽度，页表本身也占主存空间。
