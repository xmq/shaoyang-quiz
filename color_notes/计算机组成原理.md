# 计算机组成原理：重点与易错

## 第1章 计算机系统概论

### 存储程序与系统组成
- 🔴 **核心知识**：经典冯·诺依曼机：五大部件、二进制、指令与数据同存且按地址访问、操作码与地址码、存储程序、运算器中心。
- 🔵 **方法与例题**：存储程序是把程序和数据预先存入存储器；程序控制使机器按程序规定的顺序自动执行。现代教材硬件结构通常以存储器为中心。
- ⚫ **易混易错**：五部件为运算器、控制器、存储器、输入、输出；CPU不含全部主存和外设。执行顺序可转移，“中心”也不是问谁发控制信号。

### 性能指标与时间计算
- 🔴 **核心知识**：CPU时间=指令数×平均CPI÷时钟频率；时钟周期是频率倒数，吞吐率表示单位时间完成量，响应时间表示单个任务完成时长。
- 🔵 **方法与例题**：100万条指令、CPI为2、主频1GHz时，CPU时间为2毫秒；比较机器时必须同时核对指令数、CPI和频率。
- ⚫ **易混易错**：主频高不保证程序快，MIPS也不能脱离指令集比较；CPU时间通常不含I/O等待，bit与Byte、MHz与GHz先统一单位。

### 机器字长、指令字长与存储字长
- 🔴 **核心知识**：机器字长是一次整数运算处理的位数；指令字长是一条机器指令的总位数；存储字长是一个存储字的位数。
- 🔵 **方法与例题**：32位CPU、16位指令、64位存储字，三者分别为32、16、64位，不要求相等。
- ⚫ **易混易错**：按字节编址只说明每个地址对应1B，不能推出三个字长均为8位；地址位数描述可区分多少地址。

## 第2章 计算机的发展及应用

### 器件演进与软硬件层次
- 🔴 **核心知识**：主要器件常按电子管、晶体管、集成电路、大规模集成演进；语言层次说明程序到硬件的实现路径。
- 🔵 **方法与例题**：识别代际看主要电子器件；高级语言需经编译或解释，汇编需汇编器，CPU最终执行机器指令。
- ⚫ **易混易错**：不要把电子、通用、可编程、存储程序等“第一”的限定混为一谈；新代器件也不保证主频单项必升。

### 应用场景与并行加速边界
- 🔴 **核心知识**：实时控制主要约束响应期限，科学计算偏数值运算，信息管理偏记录处理；多核加速仍受串行部分限制。
- 🔵 **方法与例题**：可并行比例p、该部分加速n倍时，理想S=1/[(1−p)+p/n]；80%用4核加速得2.5倍。
- ⚫ **易混易错**：场景可跨类别，应按主要任务判断；并行公式忽略通信同步，实际加速可能更低，不能只按核数相乘。

## 第3章 系统总线

### 总线结构与带宽
- 🔴 **核心知识**：地址总线选择对象，数据总线传送内容，控制总线携带读写和时序信号；总线带宽由数据宽度、频率和每周期传输次数共同决定。
- 🔵 **方法与例题**：32位总线每周期传1次、100MHz时理论带宽为4B×100M=400MB/s；若双倍传输再乘2。
- ⚫ **易混易错**：地址总线宽度决定可寻址范围而非一次数据量；理论带宽不含仲裁、等待和协议开销，MB/s与Mb/s相差8倍。

### 总线仲裁决定谁先传
- 🔴 **核心知识**：共享总线多个主设备申请时要仲裁；链式靠近者优先，计数查询逐号轮询，独立请求以更多线换灵活裁决。
- 🔵 **方法与例题**：先识别谁是主设备，再按给定优先级授予控制；CPU以外，获准的DMA控制器也能主动发起传输。
- ⚫ **易混易错**：链式固定优先级可能使远端等待；仲裁只决定使用权，数据何时有效还需通信时序，不能混为同一件事。

### 异步总线四相握手
- 🔴 **核心知识**：异步握手用请求与应答确认双方状态：主设备置请求，从设备数据有效后应答，采样撤请求，最后撤应答。
- 🔵 **方法与例题**：沿地址先稳定、请求、应答、采样、撤销逐步检查；半同步则保留时钟并用READY或WAIT延长等待。
- ⚫ **易混易错**：请求不表示读数据已经有效；同步与异步的关键是定时方式，不能用串行并行或数据位数替代判断。

## 第4章 存储器

### 存储层次与局部性
- 🔴 **核心知识**：寄存器、Cache、主存、外存按速度、容量和成本分层；时间局部性是近期访问可能再访问，空间局部性是邻近地址可能被访问。
- 🔵 **方法与例题**：循环重复访问数组兼有时间和空间局部性；判断层次作用时看它是在缩短CPU等待、扩充容量还是提供持久保存。
- ⚫ **易混易错**：Cache和主存通常易失，外存速度慢但持久；层次对程序呈现近似大容量低成本存储，并不让所有访问一样快。

### 主存容量、编址与芯片扩展
- 🔴 **核心知识**：n根地址线可选2^n个编址单元，容量=单元数×每单元位数；位扩展增加字长，字扩展增加单元数，常用片选区分芯片。
- 🔵 **方法与例题**：16位地址、按字节编址容量为64KiB；用8K×8芯片组成32K×16需字扩4倍、位扩2倍，共8片。
- ⚫ **易混易错**：按字编址还要乘字长；地址线数量与数据线宽度职责不同，K在存储容量题常按1024解释。

### Cache映射与平均访存时间
- 🔴 **核心知识**：直接、全相联、组相联决定块可放哪里，平均时间还取决于命中时长、失效率与额外代价。
- 🔵 **方法与例题**：先区分地址映射任务还是时间估算任务；映射核对有效位和标记，时间则先统一题目口径。
- ⚫ **易混易错**：命中率高不保证所有程序都快；Cache未命中、TLB未命中和缺页属于不同层次，不能混算。

### 虚拟地址、页表与TLB
- 🔴 **核心知识**：MMU用页表把虚拟页号映射为物理页框号，页内偏移不变；TLB缓存近期页表项，缺页则需操作系统从外存调入页面。
- 🔵 **方法与例题**：4KiB页取低12位偏移，页表用页框替换页号；串行模型EAT=h(ε+T)+(1−h)(ε+2T)，缺页另算。
- ⚫ **易混易错**：Cache未命中、TLB未命中和缺页属于不同层次；虚拟地址宽度不必等于物理地址宽度，页表本身也占主存空间。

### Cache地址拆分与命中
- 🔴 **核心知识**：组数=数据容量÷块大小÷路数，块内偏移取log₂块大小，组索引取log₂组数，其余高位为标记。
- 🔵 **方法与例题**：16KiB、64B块、4路、32位地址得到64组，低6位偏移、再6位组号、余20位标记。
- ⚫ **易混易错**：容量指数据区还是含标记要看题意；行号相同不代表命中，仍须有效位为真且标记匹配。

### 平均访存时间按口径算
- 🔴 **核心知识**：常见串行口径AMAT=命中时间+失效率×额外失效代价；总失效时长已含首查时要改用加权式。
- 🔵 **方法与例题**：命中1ns、失效5%、额外代价40ns，平均1+0.05×40=3ns；先写代价是额外还是总计。
- ⚫ **易混易错**：不能既按失效总时间加权又重复加首次查询；是否串行、是否考虑写回与缺页都应服从题设。

### 低位交叉存储的模块定位
- 🔴 **核心知识**：低位交叉让连续字地址轮流落入不同模块；m模块时模块号=地址mod m，模块内地址=⌊地址/m⌋。
- 🔵 **方法与例题**：4路存储的字地址10落模块2、模块内地址2；连续流可重叠访问，实际节拍仍受总线和模块周期约束。
- ⚫ **易混易错**：公式先核对题目给字地址还是字节地址；连续访问同一模块仍会冲突，不能认为所有随机访问都变快。

### 奇偶校验与汉明纠错
- 🔴 **核心知识**：奇偶位检查1的总数奇偶，能发现奇数个位错但不能定位；汉明码用多组校验的综合值定位单比特错误。
- 🔵 **方法与例题**：k数据位需r校验位满足2^r≥k+r+1；校验位放1、2、4等位置，综合失败组的位权可求错误位置。
- ⚫ **易混易错**：普通汉明码不能保证纠正双错；加整体奇偶位才可按SECDED规则实现单错纠正、双错检测，别夸大能力。

### 磁盘定位与平均访问时间
- 🔴 **核心知识**：磁盘访问一般经历寻道、旋转等待、传输；r转每分的平均旋转等待约30/r秒，SSD没有机械旋转等待。
- 🔵 **方法与例题**：7200rpm每转约8.33ms，平均等待约4.17ms；再加给定寻道、传输和控制开销，先统一时间单位。
- ⚫ **易混易错**：容量的CHS模型需分清柱面、磁头、扇区及编号起点；LBA是逻辑块编号，不保证直接暴露实际磁盘几何。

### 存储器按存取方式分类
- 🔴 **核心知识**：随机按地址且时间与位置基本无关；顺序按物理顺序；直接先定位区域再顺序取；相联按内容匹配。
- 🔵 **方法与例题**：半导体主存、磁带、磁盘分别对应随机、顺序、直接；相联查找可用于TLB。
- ⚫ **易混易错**：存取方式不等于断电保持能力；SRAM无需刷新仍通常易失。CAM按内容访问，不能与Cache全相联映射混作同一定义。

## 第5章 输入输出系统

### I/O控制、中断与DMA
- 🔴 **核心知识**：DMA为直接存储器存取；DMA控制器搬设备与主存间数据。程序中断方式由CPU执行服务程序搬数据。
- 🔵 **方法与例题**：传统模型的外部可屏蔽中断须有效未屏蔽请求、开中断、指令结束；DMA可在机器周期末取得总线后传送，不必等整指令。
- ⚫ **易混易错**：CPU关中断不等于禁止DMA；DMA仍需初始化、结束处理及总线仲裁。DMA完成可再发中断，具体边界按模型。

### I/O接口的三个寄存器
- 🔴 **核心知识**：数据寄存器存内容，状态寄存器报ready等状态，控制寄存器接启动等命令；接口协调设备和总线的速差。
- 🔵 **方法与例题**：输入顺序为写启动、设备完成置就绪、CPU查状态、读数据；先分清在读状态还是在读真正的数据。
- ⚫ **易混易错**：端口寄存器不是设备全部内存；统一编址可用访存指令，但不代表无条件更快，清就绪规则按设备约定。

### 程序查询的忙等开销
- 🔴 **核心知识**：查询方式反复读状态，未就绪继续等，就绪后传数据；CPU时间占比约为每秒查询次数×每次拍数÷主频。
- 🔵 **方法与例题**：每秒1000次、每次20拍、主频1MHz，占比2%；题目若另有数据处理时间，应在查询成本之外计入。
- ⚫ **易混易错**：查询频繁会占CPU，间隔太长可能来不及读设备；状态未就绪时不能把数据寄存器旧值当新数据使用。

## 第6章 计算机的运算方法

### 数制、编码与位权
- 🔴 **核心知识**：二、八、十六进制按位权表示数，二进制与十六进制可每4位互换；BCD编码十进制数字，ASCII和Unicode处理字符。
- 🔵 **方法与例题**：二进制101101按位权得45，也可分组为2D十六进制；小数转换按2反复乘取整，并明确允许的精度。
- ⚫ **易混易错**：数值45、字符“45”和BCD 45编码不同；进制下标不是数的一部分，补位方向和小数点位置不能改变。

### 原码、反码、补码与溢出
- 🔴 **核心知识**：正数三种机器码相同，负数补码由原码数值位取反加1；n位补码范围为−2^(n−1)到2^(n−1)−1，加减统一用补码完成。
- 🔵 **方法与例题**：8位−5为11111011；同号数相加得到异号结果说明有符号溢出，127+1得到10000000即溢出。
- ⚫ **易混易错**：最高位进位不能单独判断有符号溢出；补码最小负数没有对应正数，符号扩展要复制符号位而非补0。

### 定点与浮点表示
- 🔴 **核心知识**：定点数的小数点位置固定，浮点数由符号、阶码和尾数组成；规格化通过调整阶码和尾数保持数值，范围主要由阶码决定。
- 🔵 **方法与例题**：单精度按1/8/23位拆分，正常数实际阶=E−127并补隐藏1；如0｜10000001｜010…=1.25×2²=5。
- ⚫ **易混易错**：浮点范围大不等于所有数精确，尾数位决定精度；对阶通常让小阶向大阶移动，会丢失低位有效数字。

### 移位先辨符号与位宽
- 🔴 **核心知识**：逻辑移位补0，补码算术右移复制符号位，算术左移补0但须查溢出；循环移位将移出位接回另一端。
- 🔵 **方法与例题**：8位补码11110100即−12，算术右移一位为11111010即−6；按给定字长写完整位串再解释结果。
- ⚫ **易混易错**：右移有符号奇数还涉及舍入约定，左移可能丢有效位；带进位循环另含CF，不能当普通乘除2计算。

### 移位相加逐位求乘积
- 🔴 **核心知识**：逐位乘法根据乘数最低位决定是否累加当前被乘数，再左移被乘数、右移乘数，逐步形成部分积。
- 🔵 **方法与例题**：4位3×5用8位积：乘数0101先加3，移位后跳过6，再加12得15；每轮写部分积防漏项。
- ⚫ **易混易错**：积宽需足够，两个n位无符号数最多需2n位；补码Booth还需算术右移与额外位，不能直接套无符号流程。

### 逐位试商与余数恢复
- 🔴 **核心知识**：恢复余数法每轮带入被除数一位后试减除数，非负商1，负则商0并恢复；最终检查被除数=除数×商+余数。
- 🔵 **方法与例题**：13÷3带入1101，保留余数依次1、0、0、1，商0100；试减负数是中间状态，不是最终余数。
- ⚫ **易混易错**：除数为0须处理，带符号商和余数另按约定；不恢复法末尾负余数需加除数修正，不能漏最后一步。

### 浮点加减的对阶与规格化
- 🔴 **核心知识**：加减先对阶，把小阶尾数右移，再做尾数运算；右规尾数除2且阶加1，左规尾数乘2且阶减1。
- 🔵 **方法与例题**：6+2.5写成1.1×2²+0.101×2²=10.001×2²=1.0001×2³；最后按精度舍入并检查阶码。
- ⚫ **易混易错**：对阶可能丢低位，舍入不是见1就进；结果为0须单独处理，不能无限左规，也不把特殊值套正常数公式。

### ALU加减与状态标志
- 🔴 **核心知识**：ALU用功能选择完成算术或逻辑操作；减法可让B按位取反并把最低位进位置1，从而复用加法器。
- 🔵 **方法与例题**：CF看无符号最高位进位，OF看有符号越界；4位0111+0001=1000时CF=0、OF=1。
- ⚫ **易混易错**：CF与OF不等价，位宽和类型必须固定；符号位为1也不必然溢出，负数的正常结果本来就可能为1。

### Booth位对判断与整体右移
- 🔴 **核心知识**：初始A=0、附加位q=0；看(Q最低位,q)，01加M、10减M、00/11不加，然后将A、Q、q整体算术右移。
- 🔵 **方法与例题**：4位−2×3，M=1110、Q=0011；每轮移位后A/Q/q依次0001/0001/1、0000/1000/1、1111/0100/0、1111/1010/0，积11111010即−6。
- ⚫ **易混易错**：必须先按位对加减再整体右移，A左端复制符号位；不能分别逻辑右移，最小负数求相反数还需扩位防溢出。

## 第7章 指令系统

### 指令、寻址与RISC/CISC
- 🔴 **核心知识**：指令系统是一台计算机所能执行的全部机器指令的集合。RISC为精简指令集计算机，CISC为复杂指令集计算机。
- 🔵 **方法与例题**：指令寻址分顺序和跳跃；数据寻址确定操作数或有效地址，如基址1000加位移20得到1020。
- ⚫ **易混易错**：微指令集合不等于机器指令系统；立即数是操作数，直接地址指向操作数；RISC/CISC不表示谁必然更快。

### 指令字段位数与编码
- 🔴 **核心知识**：指令格式分配操作码、寄存器、立即数等字段；定长操作码m位最多2^m种编码，字段用途决定解释。
- 🔵 **方法与例题**：32位指令扣6位操作码和两个5位寄存器字段，剩16位；若为补码立即数，范围−32768至32767。
- ⚫ **易混易错**：机器字长不等于指令长度；扩展操作码需避免译码冲突，不能把最短操作码位数当全部指令种数上限。

## 第8章 CPU的结构和功能

### CPU部件与指令周期
- 🔴 **核心知识**：PC为程序计数器，IR为指令寄存器；MAR保存访存地址，MDR保存读写数据；ALU算术逻辑单元，CU控制单元。
- 🔵 **方法与例题**：时钟周期是基本时间单位；机器周期完成一次基本操作；指令周期含取指与执行全部时间。数量关系由具体机器规定。
- ⚫ **易混易错**：PC保存地址而IR保存指令；CU不等于整个CPU。三种周期不必相等，也不能把一个机器周期一律当一条指令。

### 流水线与相关冲突
- 🔴 **核心知识**：流水重叠执行提高吞吐，结构冲突争资源、数据冲突等结果、控制冲突等分支，处理方式各异。
- 🔵 **方法与例题**：先区分理想吞吐题与含停顿题，再画时空图；单条延迟通常不按级数缩短，周期受最慢段限制。
- ⚫ **易混易错**：更多级数可能增加寄存器与分支代价；数据转发不能保证消除一切等待，不能跳过题给时序。

### 理想流水线填充与排空
- 🔴 **核心知识**：k段等长流水做n条需k+n−1拍：第一条先走满k拍，之后每拍再完成一条，最后仍要排空。
- 🔵 **方法与例题**：5段20条且每拍1ns，先5拍完成首条，再19拍完成其余，共24ns，而非20ns或100ns。
- ⚫ **易混易错**：公式假定各段可同时工作且无冲突停顿；阶段不等长时先找节拍，不能把总段时间当周期。

### 流水线停顿与总时间
- 🔴 **核心知识**：从理想总拍数出发加入实际等待拍，再乘流水时钟周期；停顿在哪一级由相关关系决定。
- 🔵 **方法与例题**：5段10条理想14拍，加2拍停顿得16拍，周期1.6ns故总25.6ns；先列周期数再换时间。
- ⚫ **易混易错**：已经包含停顿的时间表不能再次加罚时；无转发数据相关要等写回，能否同拍读写须按约定。

### 中断屏蔽与嵌套顺序
- 🔴 **核心知识**：请求优先级选同时请求的响应次序，屏蔽字控制服务时允许谁打断；开放嵌套前应妥善保存断点和现场。
- 🔵 **方法与例题**：若高A可打断低B，执行为主程序→B前半→A→B后半→主程序；各层恢复到自己保存的返回位置。
- ⚫ **易混易错**：高优先级不代表一定可嵌套，还受开关中断和屏蔽条件限制；不可屏蔽中断和异常规则也不能直接套用。

## 第9章 控制单元的功能

### 微操作按通路安排节拍
- 🔴 **核心知识**：微操作是寄存器传送或ALU等基本动作；安排节拍先查依赖、总线源和端口，只有资源不冲突才可并行。
- 🔵 **方法与例题**：单总线算R1+R2可先R1送Y，再R2与Y相加进Z，最后Z回R1；每拍只允许一个源驱动共享总线。
- ⚫ **易混易错**：不能凭箭头数量判断可否同拍；独立PC增量器可与取指传送并行，若共用ALU则要另排节拍避免争用。

### 控制时序与就绪等待
- 🔴 **核心知识**：控制信号由操作码、当前状态、条件和外部就绪共同决定；慢存储器未READY时应保持等待而非读取旧数据。
- 🔵 **方法与例题**：READ_WAIT遇READY=0自环，READY=1锁存数据再转下一态；同步按时钟，异步按完成应答推动。
- ⚫ **易混易错**：操作码译码只说明做什么，不能独自决定何时做；机器周期与时钟周期的对应关系应按具体题设判断。

## 第10章 控制单元的设计

### 硬布线控制方程从状态表来
- 🔴 **核心知识**：硬布线设计先列指令微操作和状态，再写输出与转移方程；译码线、节拍与条件组合产生寄存器和总线控制。
- 🔵 **方法与例题**：若F1、E1均是读等待态，可写MemRead=F1∨E1，MDRin=(F1∨E1)∧READY，未就绪留本态。
- ⚫ **易混易错**：方程依给定接口与数据通路，不能从另一模型照搬；非法操作码和复位入口也要有确定处理，防止误写。

### 微程序入口与下一微地址
- 🔴 **核心知识**：机器PC访问主存指令，微PC访问控存微指令；微指令发控制动作，下一地址可顺序、显式给出或条件分派。
- 🔵 **方法与例题**：取指00→01等待→02装IR→03分派→执行入口20，末尾回00；入口分派要满足新IR已生效的时序。
- ⚫ **易混易错**：机器指令与微指令不是一对一；回取指微入口不等于把机器PC清0，控存与保存用户程序的主存也不同。

### 微指令编码与控存容量
- 🔴 **核心知识**：水平微指令通常较宽且可并行发多命令，垂直编码较紧凑但需译码；互斥动作可分字段以节省位数。
- 🔵 **方法与例题**：一组4个互斥动作加空操作共5种需3位；控存64条、每条24位，容量1536bit即192B。
- ⚫ **易混易错**：可并行动作不应放进只能选一个的同一字段；容量要计全部字段，含下一地址和条件位，不只数控制线。
