# 信号与系统：重点与易错

## 第1章 信号与系统概述
### 信号分类、周期与能量功率
- 🔴 **核心知识**：连续与离散描述时间取值，模拟与数字还涉及幅度；正弦信号满足T=2π/ω，有限能量信号与有限非零平均功率信号判据不同。
- 🔵 **方法与例题**：3cos(4πt+φ)的周期为0.5秒；先判定义域和周期，再按积分或周期平均值判断能量、功率。
- ⚫ **易混易错**：数字信号不只是“离散时间”，初相位不改变正弦周期；非零周期信号通常能量无穷但平均功率有限。

### 时间变换与冲激阶跃
- 🔴 **核心知识**：x(t−t0)右移，x(−t)反折，x(at)按1/|a|缩放时间；冲激面积为1并满足筛选性质，阶跃导数为冲激。
- 🔵 **方法与例题**：处理x(at+b)先令原波形关键点满足at+b=t关键，再解新位置；冲激积分直接取被积函数在冲激位置的值。
- ⚫ **易混易错**：平移与尺度次序会改变结果，不能只看符号猜方向；冲激不是在零点取无穷大的普通函数。

## 第2章 连续时间系统的时域分析
### 线性、时不变、因果与稳定
- 🔴 **核心知识**：线性检验叠加齐次，时不变比较输入与输出同量平移，因果不使用未来输入，BIBO稳定要求有界输入产生有界输出。
- 🔵 **方法与例题**：y(t)=2x(t)+1因零输入有常数而非线性；y(t)=x(t+1)使用未来输入而非因果，每项都要代定义。
- ⚫ **易混易错**：线性不保证时不变、因果或稳定；“输出随时间变化”不等于系统时变，延迟系统也可以时不变。

### 零输入、零状态与总响应
- 🔴 **核心知识**：零输入响应由初始储能产生，零状态响应由外部输入产生；线性系统总响应等于两者之和，卷积只直接给零状态部分。
- 🔵 **方法与例题**：解y′+ay=bx时先写初值；令x=0求齐次响应，令初值为0求受迫响应，最后相加并核对初始值。
- ⚫ **易混易错**：零输入不等于输出为零，零状态也不等于没有输入；非零初始条件下不能把x*h直接当作总响应。

## 第3章 卷积与零状态响应
### 冲激响应与LTI判据
- 🔴 **核心知识**：LTI系统零状态输出y=x*h；冲激输入δ(t−t0)得到h(t−t0)，因果LTI要求h在t<0为零，稳定要求h绝对可积。
- 🔵 **方法与例题**：δ(t−1)与e^(−t)u(t)卷积，直接右移得到e^{−(t−1)}u(t−1)；再检查起始时刻是否为1。
- ⚫ **易混易错**：因果与绝对可积判据只可直接用于LTI系统；冲激响应描述零状态行为，不自动包含初始储能。

### 卷积反折、平移与重叠
- 🔴 **核心知识**：连续卷积依次反折h(τ)、平移成h(t−τ)、找重叠区、相乘积分；离散卷积把最后一步改为逐项求和。
- 🔵 **方法与例题**：两个长度2且值均为1的序列卷积为[1,2,1]；有限序列完整卷积长度为Lx+Lh−1。
- ⚫ **易混易错**：平移变量是τ而输出参数是t，重叠端点会随t改变；逐点相乘不是卷积，循环卷积也不等于线性卷积。

## 第4章 傅里叶变换与频域分析
### 傅里叶级数与谱线
- 🔴 **核心知识**：周期信号由基频及整数倍谐波组成，复指数系数按一个周期积分求得；周期信号频谱离散，非周期信号通常是连续频谱。
- 🔵 **方法与例题**：先求T0与ω0，再利用奇偶和半波对称性判断哪些系数为零，最后计算剩余积分并画幅相谱。
- ⚫ **易混易错**：谱线间隔由基频决定，不由最高谐波决定；截去高频会让边沿变圆，频谱不是另一份独立信号。

### 傅里叶变换与滤波
- 🔴 **核心知识**：时域卷积对应频域相乘，时移只给频谱增加线性相位；LTI滤波器通过H(jω)选择或衰减不同频率分量。
- 🔵 **方法与例题**：求输出先写Y=XH，再按通带保留谱分量；x(t−t0)乘e^(−jωt0)，所以幅度谱不变、相位改变。
- ⚫ **易混易错**：时域相乘对应频域卷积而非相乘；时间压缩会使频谱展宽，并伴随不能遗漏的幅度因子。

## 第5章 拉普拉斯变换与Z变换
### 拉普拉斯变换、极点与ROC
- 🔴 **核心知识**：X(s)必须连同ROC解释；连续因果有理系统ROC在最右极点右侧，即Re(s)>max Re(p_i)；稳定系统ROC包含jω轴，极点本身不属于ROC。
- 🔵 **方法与例题**：微分方程先变为s域代数式，代入初值或声明零初始，再部分分式反变换，并用初值和极点复核。
- ⚫ **易混易错**：相同代数式配不同ROC可对应不同信号；只看极点左半平面不能替代因果与ROC条件。

### Z变换与差分方程
- 🔴 **核心知识**：X(z)=Σx[n]z^(−n)，零初始时H=Y/X；离散有理因果系统ROC在最外极点外，稳定还要求包含单位圆。
- 🔵 **方法与例题**：y[n]−0.5y[n−1]=x[n]得H=1/(1−0.5z⁻¹)，因果ROC为|z|>0.5并包含单位圆，所以稳定。
- ⚫ **易混易错**：右边与左边序列可有同一代数式而ROC不同；单边Z变换处理初值时不能套双边零状态结论。

## 第6章 抽样定理与离散化
### 采样条件、混叠与重建
- 🔴 **核心知识**：最高频率fm的带限信号通常要求fs>2fm；低采样使频谱副本重叠产生混叠，ADC前需抗混叠滤波并留过渡带。
- 🔵 **方法与例题**：4kHz信号理论奈奎斯特速率为8kHz；9kHz信号以10kHz采样会折叠成1kHz等效分量。
- ⚫ **易混易错**：两倍频率是理论边界而非工程保险值；采样后混叠不能仅靠提高量化位数或软件滤波唯一恢复。

### 量化步长与数字化链路
- 🔴 **核心知识**：数字化按抗混叠、采样保持、量化、编码进行；N位均匀量化有2^N级，满量程V时步长约V/2^N。
- 🔵 **方法与例题**：8位0至5V量化步长约19.5mV，理想误差通常不超过半步长；先确认量程是否含两个端点定义。
- ⚫ **易混易错**：采样率控制时间分辨率，位数控制幅值分辨率；提高位数不能消除模拟噪声，也不能修复混叠。

## 第7章 系统分析方法的联系
### 时域、频域与复频域选择
- 🔴 **核心知识**：时域适合瞬态、初值和卷积，频域适合谐波、带宽和滤波，复频域适合方程、零极点与稳定分析。
- 🔵 **方法与例题**：先判连续或离散、LTI与否及初始条件，再选择卷积、傅里叶、拉普拉斯或Z变换，并用另一视角复核。
- ⚫ **易混易错**：三种域描述同一系统但适用条件不同；有初始储能时Y=HX只代表零状态部分，变换式还需收敛域。
