# 信号与系统：重点与易错

## 第1章 信号与系统概述
### 信号分类、周期与能量功率

- 🔴 **核心知识**：连续/离散按时间定义，模拟/数字还看幅值；能量E为模平方积分，功率P为长期平均模平方。
- 🔵 **方法与例题**：e^(−2t)u(t)能量∫₀∞e^(−4t)dt=1/4；cos(3πn/4)最小整数周期8。
- ⚫ **易混易错**：能量公式不可漏平方；离散正弦须ΩN=2πk有整数解，连续正弦周期规则不可照搬。

### 时间变换与冲激阶跃

- 🔴 **核心知识**：x(t−t0)右移，x(−t)反折，x(at)按|a|缩放；连续δ以单位面积和筛选性质定义。
- 🔵 **方法与例题**：原非零区间[0,3]，x(2t−4)要求0≤2t−4≤3，得到[2,3.5]。
- ⚫ **易混易错**：先解关键点位置，再连波形；x(2t−4)右移2而非4，连续冲激不是普通有限高度脉冲。

## 第2章 连续时间系统的时域分析
### 线性、时不变、因果与稳定

- 🔴 **核心知识**：线性保持叠加比例；时不变使输入平移对应同样输出平移；因果不看未来，BIBO稳定使有界输入输出有界。
- 🔵 **方法与例题**：y=tx线性；延迟输入给t x(t−t0)，延迟输出给(t−t0)x(t−t0)，不同，故时变。
- ⚫ **易混易错**：性质逐项独立检查；y=2x+1零输入不为0，非线性，并非因含常数就一定时变。

### 零输入、零状态与总响应

- 🔴 **核心知识**：线性系统总响应=零输入+零状态；前者仅由初始状态产生，后者令初始状态0仅看输入。
- 🔵 **方法与例题**：y′+2y=1、y(0+)=3，yzi=3e^(−2t)，yzs=(1−e^(−2t))/2，总y=1/2+2.5e^(−2t)。
- ⚫ **易混易错**：有初值时总Y通常不等于HX；零状态不能只取常值特解而漏初值匹配项。

## 第3章 卷积与零状态响应
### 冲激响应与LTI判据

- 🔴 **核心知识**：LTI零状态响应y=x*h；因果要求h(t)=0（t<0），BIBO稳定要求∫|h|dt有限，离散改绝对求和。
- 🔵 **方法与例题**：h=e^(−t)u(t)积分绝对值为1，因果且稳定；输入δ(t−1)，输出h(t−1)。
- ⚫ **易混易错**：冲激响应判据限定LTI；因果不自动稳定，e^t u(t)因果却绝对积分发散。

### 卷积反折、平移与重叠

- 🔴 **核心知识**：连续卷积y(t)=∫x(τ)h(t−τ)dτ，按反折、平移、找交集、乘积积分执行。
- 🔵 **方法与例题**：两个[0,1]单位矩形，交集[max(0,t−1),min(1,t)]：0～1输出t，1～2输出2−t，其他0。
- ⚫ **易混易错**：积分变量τ，t为本次参数；只有乘积高度为1时，积分才直接等于重叠长度。

## 第4章 傅里叶变换与频域分析
### 傅里叶级数与谱线

- 🔴 **核心知识**：周期T0，ω0=2π/T0；x=ΣCk e^(jkω0t)，Ck=(1/T0)∫周期x e^(−jkω0t)dt。
- 🔵 **方法与例题**：奇方波±1、周期2π，仅奇次正弦项，b1=4/π、b3=4/(3π)，Ck须与三角系数转换。
- ⚫ **易混易错**：谱线在整数倍基频；跳变处级数取左右极限平均，有限谐波不能精确恢复竖直边沿。

### 傅里叶变换与滤波

- 🔴 **核心知识**：X=∫x e^(−jωt)dt，逆变换带1/(2π)；零状态LTI有Y=XH，h的变换是频率响应。
- 🔵 **方法与例题**：e^(−at)u(t)↔1/(a+jω)，a>0；理想低通|ω|≤ωc增益1，h=sin(ωct)/(πt)。
- ⚫ **易混易错**：理想低通h在负时间非零，不能严格实时因果实现；频域乘积不适用于任意非线性系统。

### 傅里叶奇偶与系数

- 🔴 **核心知识**：三角级数常数项a0/2；实偶信号bn=0，实奇信号a0=an=0，半波反对称另使偶次谐波0。
- 🔵 **方法与例题**：±1奇方波：bn=2[1−cos(nπ)]/(nπ)，奇n为4/(nπ)，偶n为0。
- ⚫ **易混易错**：奇对称只消余弦项，并不独自保证消除偶次谐波；C0=a0/2，不是a0。

### 时移与尺度的频谱变化

- 🔴 **核心知识**：x(t−t0)↔e^(−jωt0)X；x(at)↔X(jω/a)/|a|，a≠0；调制余弦形成两侧频移副本。
- 🔵 **方法与例题**：原谱支撑|ω|≤10，x(2t)支撑变|ω|≤20且谱幅乘1/2；纯时移不改幅度谱。
- ⚫ **易混易错**：时移改相位，尺度改频率轴且改幅度；不能漏1/|a|或把时移当频移。

## 第5章 拉普拉斯变换与Z变换
### 拉普拉斯变换、极点与ROC

- 🔴 **核心知识**：双边X(s)=∫x e^(−st)dt，极点不在ROC；有理因果ROC在最右极点右方，稳定须含虚轴。
- 🔵 **方法与例题**：1/(s+2)配Re(s)>−2对应e^(−2t)u(t)，因果稳定；配Re(s)<−2对应左边信号。
- ⚫ **易混易错**：同一代数式配不同ROC可不同；比较连续极点的实部，不是模长。

### Z变换与差分方程

- 🔴 **核心知识**：X(z)=Σx[n]z⁻ⁿ；零状态H=Y/X，有理因果ROC在最外极点之外，稳定须含单位圆。
- 🔵 **方法与例题**：y[n]=0.5y[n−1]+x[n]，静止单位样值输入得1、0.5、0.25；H=1/(1−0.5z⁻¹)。
- ⚫ **易混易错**：极点0.5要配因果ROC|z|>0.5才可推出稳定；非零初值需另加零输入项。

### 部分分式与反变换

- 🔴 **核心知识**：先变换方程、解Y、拆部分分式，再按ROC及左右边属性反变换，最后检查初值及原方程。
- 🔵 **方法与例题**：y′+2y=e^(−t)u(t)、零初值：Y=1/[(s+1)(s+2)]=1/(s+1)−1/(s+2)，y=(e^(−t)−e^(−2t))u(t)。
- ⚫ **易混易错**：非零y(0−)时单边导数为sY−y(0−)；求系数代极点不表示变换在那里收敛。

## 第6章 抽样定理与离散化
### 采样条件、混叠与重建

- 🔴 **核心知识**：最高fm严格带限信号通常取fs>2fm并用采样前抗混叠滤波；2fm为理论边界。
- 🔵 **方法与例题**：9 kHz以10 kHz采样，9−10=−1 kHz，对实余弦等效1 kHz，已失去原频率唯一性。
- ⚫ **易混易错**：临界处正弦可能全采到零点；采样后滤波不能无条件恢复已混叠的模拟分量。

### 量化步长与数字化链路

- 🔴 **核心知识**：数字化为抗混叠→抽样保持→量化→编码；N位均匀Δ=满量程范围/2^N。
- 🔵 **方法与例题**：8位0～5 V：Δ≈19.53 mV；无过载、中点重建的误差幅值界约9.77 mV。
- ⚫ **易混易错**：半步误差界须约定中点重建；位数提高幅值分辨率，采样率提高时间分辨能力，两者不可替代。

## 第7章 系统分析方法的联系
### 时域、频域与复频域选择

- 🔴 **核心知识**：LTI系统时域用h及卷积，频域用H(jω)滤波，复频域用H(s)/H(z)及ROC，初值要单列。
- 🔵 **方法与例题**：RC=1：y′+y=x，H(s)=1/(s+1)，h=e^(−t)u(t)，单位阶跃输出1−e^(−t)。
- ⚫ **易混易错**：H(jω)须存在且与ROC对应；非零状态的总响应不能只用频谱相乘。
