# 模拟电子技术：重点与易错

## 第1章 绪论与半导体基础
### PN结与器件模型

- 🔴 **核心知识**：PN结由扩散形成耗尽层及内建电场；正偏削弱势垒，反偏增强势垒。N/P型整体均电中性。
- 🔵 **方法与例题**：P端0 V、N端5 V为反偏；理想二极管导通压降0，硅管恒压降模型常取0.7 V。
- ⚫ **易混易错**：少子引起反向漏电，超过击穿值电流可显著增大；单向导电不等于绝对无反向电流。

## 第2章 半导体二极管及其应用
### 二极管导通、整流滤波稳压

- 🔴 **核心知识**：先选模型并判断极性；整流得到脉动直流，滤波减小纹波，稳压在规定输入负载范围保持输出。
- 🔵 **方法与例题**：5 V经1 kΩ串硅管：假设导通得(5−0.7)/1k=4.3 mA，再核对假设。
- ⚫ **易混易错**：桥式每次两管导通；0.9U只适用于理想、纯电阻负载无电容滤波的全波平均值。

## 第3章 晶体管与基本放大电路
### BJT/MOS工作区与开关

- 🔴 **核心知识**：BJT放大区发射结正偏、集电结反偏；N增强MOS在VGS>VT且VDS≥VGS−VT时为理想饱和区。
- 🔵 **方法与例题**：MOS的VGS=3 V、VT=1 V，VDS=0.5 V为三极管区、2.5 V为饱和区。
- ⚫ **易混易错**：BJT饱和多作低压降开关，MOS饱和可作小信号放大；两种“饱和”不能混同。

### 静态工作点、共射增益与削顶

- 🔴 **核心知识**：Q点是无交流输入时直流电压、电流；先使器件处于所需工作区，再计算小信号变化。
- 🔵 **方法与例题**：共射IC增加→RC压降增加→UC下降；Q点过近截止或饱和边界时一侧摆幅不足。
- ⚫ **易混易错**：“居中”便于对称摆幅但非所有电路必须精确取负载线中点；小信号增益不保证大信号不失真。

### 固定偏置静态工作点

- 🔴 **核心知识**：RB由VCC接基极、RC由VCC接集电极、E接地，放大区IB=(VCC−UBE)/RB、IC=βIB。
- 🔵 **方法与例题**：12 V、565 kΩ、2 kΩ、0.7 V、β=100：IB=20 μA，IC=2 mA，UCE=12−4=8 V。
- ⚫ **易混易错**：须回查C高于B等工作区条件；若UCE算负，放大区假设失败，不可照用βIB。

### 共射中频小信号增益

- 🔴 **核心知识**：放大区、中频、小信号、发射极交流接地且忽略输出电阻时，Au≈−β(RC∥RL)/rbe。
- 🔵 **方法与例题**：β=100、rbe=1 kΩ、RC∥RL=2 kΩ，Au=−200，1 mV输入约得−0.2 V变化。
- ⚫ **易混易错**：rbe是Q点附近的增量电阻，不是RB；RE未旁路、负载改变或信号过大时须重算。

## 第4章 多级放大、差分放大与频率响应
### 多级负载、差分与频率响应

- 🔴 **核心知识**：总增益应乘各级实际带载增益；差分级区分ud=u1−u2、uc=(u1+u2)/2；通带以规定截止点界定。
- 🔵 **方法与例题**：已计负载两级−10、−20，总增益+200，约46 dB；分项计算到对应子卡复习。
- ⚫ **易混易错**：开路增益相乘会遗漏级间负载；共模抑制比、通带宽度与总增益是不同指标。

### 级间负载分压

- 🔴 **核心知识**：前级等效为开路输出U0串Ro，后级输入Ri构成负载：Ui2=U0Ri/(Ro+Ri)。
- 🔵 **方法与例题**：U0=1 V、Ro=10 kΩ、Ri=10 kΩ，Ui2=0.5 V；Ri=90 kΩ则0.9 V。
- ⚫ **易混易错**：后级输入阻抗通常随频率变化；公式先确定该频率下等效，分压不等于后级放大增益。

### 差模、共模与抑制比

- 🔴 **核心知识**：uo=Adud+Acuc，CMRR=|Ad/Ac|，分贝值20log₁₀CMRR；越大表示共模抑制越强。
- 🔵 **方法与例题**：u1=1.01、u2=0.99 V，ud=0.02、uc=1 V；Ad=100、Ac=0.1，uo=2.1 V，CMRR=60 dB。
- ⚫ **易混易错**：差值与平均值不可混用；结果仍须在运放输入共模和输出摆幅范围内。

### 截止频率与通频带

- 🔴 **核心知识**：幅值降至中频的1/√2为−3 dB点；BW=fH−fL，一阶RC截止fc=1/(2πRC)。
- 🔵 **方法与例题**：R=10 kΩ、C=1 nF得15.9 kHz；fL=20 Hz、fH=20 kHz，BW=19980 Hz。
- ⚫ **易混易错**：同负载条件下0.707倍电压对应半功率；多极点不能全程按单极点斜率计算。

## 第5章 放大电路中的反馈
### 反馈极性、组态与闭环增益

- 🔴 **核心知识**：使净输入减小为负反馈；输出分电压/电流取样，输入分串联电压/并联电流比较。
- 🔵 **方法与例题**：同相运放输出升高→反相端反馈电压升高→净差模输入减小，为电压串联负反馈。
- ⚫ **易混易错**：稳定负反馈常可改善失真及参数敏感性，但不能消除所有噪声，也须检查高频稳定性。

### 负反馈闭环增益计算

- 🔴 **核心知识**：稳定线性负反馈，净输入ui−Fuo，Af=A/(1+AF)；|AF|足够大时近似1/F。
- 🔵 **方法与例题**：A=1000、F=0.1：Af=1000/101≈9.901，深反馈近似10。
- ⚫ **易混易错**：A、F一般为频率相关复数；不能用直流代数式自动保证整环不振荡。

### 四种负反馈的电阻判断

- 🔴 **核心知识**：串联比较使输入电阻增大，并联比较使其减小；电压取样使输出电阻减小，电流取样使其增大。
- 🔵 **方法与例题**：希望输入电阻大、输出电阻小，选电压串联；希望低输入电阻、高输出电阻，选电流并联。
- ⚫ **易混易错**：规则用于稳定负反馈且对应端口定义；不要用“电压”判输入电阻、用“串联”判输出电阻。

## 第6章 集成运算放大与信号处理
### 运放虚短虚断与比例运算

- 🔴 **核心知识**：理想线性负反馈近似u+=u−、i+=i−=0；反相Au=−Rf/R1，同相Au=1+Rf/R1。
- 🔵 **方法与例题**：反相R1=10 kΩ、Rf=50 kΩ、ui=0.2 V，输入20 μA流经反馈，uo=−1 V。
- ⚫ **易混易错**：虚短不是实际短接；比较器、反馈断开或输出饱和时不可继续列虚短。

## 第7章 波形发生与功率放大
### 比较器、迟滞与振荡

- 🔴 **核心知识**：比较器按输入差符号切换高低；迟滞为上升、下降设置不同阈值；振荡需同时满足幅度与相位条件。
- 🔵 **方法与例题**：上升阈3 V、下降阈2 V，输入2.5 V可能高也可能低，取决于之前状态。
- ⚫ **易混易错**：迟滞区内不能只凭当前电压判输出；有正反馈也不保证稳定正弦振荡。

### 功率放大与交越失真

- 🔴 **核心知识**：甲类导通360°、乙类180°、甲乙类180°～360°；乙类过零两管未充分导通形成交越死区。
- 🔵 **方法与例题**：甲乙偏置使零点附近导通重叠；纯阻正弦输出Po=Uom²/(2RL)，8 V峰值、8 Ω得4 W。
- ⚫ **易混易错**：加偏置会增加静态管耗，不能无限增大；效率Po/P直流与线性、温升分别检查。

### 迟滞阈值与历史状态

- 🔴 **核心知识**：按题给翻转方向使用上下阈值；两阈值之间保持原输出，形成回差。
- 🔵 **方法与例题**：非反相规则：初始低，上升2.5 V仍低、3.2 V变高；下降2.4 V仍高、1.8 V变低。
- ⚫ **易混易错**：反相施密特方向可能相反；历史未知且处回差区时，不能唯一判断输出。

### 正弦振荡的起振与稳幅

- 🔴 **核心知识**：目标频率环路相位2kπ；起振幅值略大于1，稳态有效环路增益约1，能量来自直流电源。
- 🔵 **方法与例题**：等R、C文氏桥f0=1/(2πRC)、F=1/3；放大增益略大于3起振，再稳幅至约3。
- ⚫ **易混易错**：一直小于1扰动衰减，一直大于1且无稳幅易削顶；仅满足其中一个条件不够。

## 第8章 直流电源、测量与电路读图
### 直流电源、采集链与排障

- 🔴 **核心知识**：电源按变压→整流→滤波→稳压；采集链按保护偏置→放大缓冲→抗混叠→ADC。
- 🔵 **方法与例题**：先测电源和Q点，再加小信号逐级测波形；最后正常与最早异常节点界定故障范围。
- ⚫ **易混易错**：整流平均值不能套滤波后峰值；提高ADC位数不能弥补前端饱和或混叠。

### 电容滤波纹波估算

- 🔴 **核心知识**：峰间近似恒负载电流放电时，ΔU≈ILΔt/C；全波整流Δt近似1/(2f电源)。
- 🔵 **方法与例题**：50 Hz全波、IL=10 mA、C=1000 μF，Δt≈10 ms，纹波约0.1 V。
- ⚫ **易混易错**：忽略导通时间等细节，只作估算；电容变大减纹波，也可能增大整流充电冲击。

### 传感器采集链选型

- 🔴 **核心知识**：高源阻信号先缓冲、微弱信号适当放大、采样前抗混叠滤波；幅值须进入ADC允许范围。
- 🔵 **方法与例题**：0～20 mV传感器送0～2 V ADC，可先考虑约100倍增益，再核对偏置、噪声和输出摆幅。
- ⚫ **易混易错**：增益过高会饱和；滤波不能无条件越强越好，必须保留有用频带。

### 二极管挡安全初检

- 🔴 **核心知识**：断电并确认电容放电后，用二极管挡比较两个方向压降；必要时隔离一端排除并联路径。
- 🔵 **方法与例题**：普通硅PN结正向约0.6～0.7 V、反向通常截止；两向近0先怀疑短路，再排除在路通路。
- ⚫ **易混易错**：不同器件压降不同；BJT两个PN结初检通过，不能证明β、漏电或动态性能合格。
