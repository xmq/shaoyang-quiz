# 模拟电子技术：重点与易错

## 第1章 绪论与半导体基础
### PN结与器件模型
- 🔴 **核心知识**：P型多数载流子为空穴，N型为电子；PN结正偏势垒降低、反偏势垒升高，形成单向导电基础。
- 🔵 **方法与例题**：先判断P端相对N端电位，再选截止、恒压降或小信号模型；模型精度要匹配题目。
- ⚫ **易混易错**：P型并非整体带正电；导通压降不是任何电流温度下都严格0.7V。

## 第2章 半导体二极管及其应用
### 二极管导通、整流滤波稳压
- 🔴 **核心知识**：先假设二极管状态并求端电压，再验证；整流变脉动直流，滤波减纹波，稳压稳定输出。
- 🔵 **方法与例题**：5V电源、LED压降2V、目标10mA，限流电阻约`(5-2)/0.01=300Ω`。
- ⚫ **易混易错**：稳压管正常工作在反向击穿区且必须限流；电解滤波电容注意极性和耐压。

## 第3章 晶体管与基本放大电路
### BJT/MOS工作区与开关
- 🔴 **核心知识**：BJT截止近似断开、放大区可用`IC≈βIB`、饱和近似导通开关；MOS由栅源电压控制但仍有导通电阻和电流边界。
- 🔵 **方法与例题**：先由结偏压或端电压判工作区，再决定是否可套β关系；驱动线圈还要检查基极/栅极驱动与续流。
- ⚫ **易混易错**：饱和后不能继续按β比例增流；阈值电压不等于MOS已经成为零压降开关。

### 静态工作点、共射增益与削顶
- 🔴 **核心知识**：静态工作点描述无信号直流状态，交流增益描述Q点附近小变化；削顶还取决于偏置和允许摆幅。
- 🔵 **方法与例题**：先看要求是IB/IC/UCE还是uo/ui；无交流输入先求Q点，小信号才求增益，单侧削顶优先核对偏置。
- ⚫ **易混易错**：不能把静态电流代作交流信号，也不能用小信号增益宣称任意幅度都可线性输出；工作区与摆幅要验证。

### 固定偏置静态工作点
- 🔴 **核心知识**：发射极接地的固定偏置先求IB，再用IC≈βIB，最后由集电极回路求UCE并验证工作区。
- 🔵 **方法与例题**：12V、565kΩ、2kΩ、β100、UBE0.7V，依次得20μA、2mA、8V，仍满足UC>UB>UE。
- ⚫ **易混易错**：计算出负UCE不能继续沿用放大区假设；若接入RE，回路还需计入IERE，不能原式硬套。

### 共射中频小信号增益
- 🔴 **核心知识**：放大区、中频小信号、发射极交流接地时，Au≈−β(RC∥RL)/rbe，rbe是小信号输入电阻。
- 🔵 **方法与例题**：β100、rbe1kΩ、交流负载2kΩ时Au≈−200；输入1mV对应输出变化约−0.2V，再检查摆幅。
- ⚫ **易混易错**：rbe不是偏置RB；RE未充分旁路、输入过大或输出削顶时，不能继续使用这一简式。
## 第4章 多级放大、差分放大与频率响应
### 多级负载、差分与频率响应
- 🔴 **核心知识**：级间负载关注前后级连接后的分压，差分关注两输入差与共模，频响关注增益随频率变化，指标不可混。
- 🔵 **方法与例题**：看到Ro/Ri先判断加载，看到u1/u2先拆差模共模，看到fL/fH先判断通带；按当前任务选择对应计算。
- ⚫ **易混易错**：空载总增益、共模抑制比和带宽是不同量；某一指标改善不代表三者都改善，输出始终受线性摆幅约束。

### 级间负载分压
- 🔴 **核心知识**：前级可看成空载输出U0串联Ro，后级Ri成为负载，实际输入Ui2=U0Ri/(Ro+Ri)。
- 🔵 **方法与例题**：U0为1V、Ro与Ri都10kΩ时Ui2=0.5V；Ri增至90kΩ则0.9V，再计后级实际增益。
- ⚫ **易混易错**：空载增益不能机械相乘；输入电阻越大通常加载越轻，但还须核查频率和具体电路条件。

### 差模、共模与抑制比
- 🔴 **核心知识**：差模ud=u1−u2，共模uc=(u1+u2)/2；线性模型uo=Adud+Acuc，CMRR=|Ad/Ac|。
- 🔵 **方法与例题**：u1=1.01V、u2=0.99V、Ad100、Ac0.1，得到ud0.02V、uc1V、输出2.1V，CMRR1000。
- ⚫ **易混易错**：CMRR越大越能抑制共模，但不是消除全部噪声；换算分贝用20log₁₀CMRR并检查摆幅。

### 截止频率与通频带
- 🔴 **核心知识**：中频幅值增益降至约0.707倍处定义常用截止点，带宽BW=fH−fL，先统一频率单位。
- 🔵 **方法与例题**：中频增益100时截止增益约70.7；fL20Hz、fH20kHz时，BW=20000−20=19980Hz。
- ⚫ **易混易错**：0.707倍电压在负载不变时对应半功率，不是电压减半；扩大频带也不能保证其他指标都改善。
## 第5章 放大电路中的反馈
### 反馈极性、组态与闭环增益
- 🔴 **核心知识**：反馈极性看净输入增减，组态看取样与接法，闭环增益看反馈强度；先确认稳定负反馈再用相关结论。
- 🔵 **方法与例题**：要求输入电阻高输出电阻低时选电压串联；求数值增益时另用A和F，不凭电压串联四字推算具体增益。
- ⚫ **易混易错**：接反相端不自动等于任意频率都稳定；组态与环路增益不同，环外噪声也不能靠负反馈全部消除。

### 负反馈闭环增益计算
- 🔴 **核心知识**：稳定负反馈中Af=A/(1+AF)，A为基本增益、F为反馈系数；先求环路乘积，再计算分母。
- 🔵 **方法与例题**：A200、F0.02，AF=4，Af=200/(1+4)=40；只有AF足够大时才近似用1/F。
- ⚫ **易混易错**：把正反馈直接套入负反馈结论会错；深反馈近似不是任意数据的精确值，还要满足稳定线性条件。

### 四种负反馈的电阻判断
- 🔴 **核心知识**：先确认稳定负反馈，再分两端：串联输入增Ri、并联输入减Ri；电压取样减Ro、电流取样增Ro。
- 🔵 **方法与例题**：希望前级少取电流且后级输出电压稳定，要Ri大、Ro小，因此选择电压串联负反馈。
- ⚫ **易混易错**：电压或电流指输出取样，串联或并联指输入比较；不能只看连接正端负端就机械判定组态。
## 第6章 集成运算放大与信号处理
### 运放虚短虚断与比例运算
- 🔴 **核心知识**：深度负反馈、线性未饱和时可用虚短虚断；反相`Au=-Rf/R1`，同相`Au=1+Rf/R1`。
- 🔵 **方法与例题**：反相R1=10kΩ、Rf=30kΩ、ui=0.4V得uo=-1.2V，再检查电源允许摆幅。
- ⚫ **易混易错**：比较器或饱和运放不能用虚短；虚断不是端子真正没有任何电流。

## 第7章 波形发生与功率放大
### 比较器、迟滞与振荡
- 🔴 **核心知识**：比较器判断输入大小，迟滞增加历史相关双阈值，振荡器维持周期输出；三者均不能默认使用线性虚短。
- 🔵 **方法与例题**：阈值附近噪声反复翻转先考虑迟滞；需无外加周期输入而持续输出正弦，考虑正反馈加选频与稳幅。
- ⚫ **易混易错**：迟滞抗抖与正弦振荡不是同一目标；正反馈不供能，阈值历史和振荡稳定条件必须按具体电路说明。

### 功率放大与交越失真
- 🔴 **核心知识**：功放关注输出功率、效率、管耗和散热；甲类线性好效率低，乙类效率高但有交越失真，甲乙类折中。
- 🔵 **方法与例题**：过零附近出现缺口优先判断乙类器件交接不连续，再检查偏置和热稳定。
- ⚫ **易混易错**：效率高不代表失真小；输出功率增加必须同时核对器件安全区和散热。

### 迟滞阈值与历史状态
- 🔴 **核心知识**：迟滞为两个转换方向设不同阈值；输入在阈值之间保持原状态，因此判断必须先知道历史。
- 🔵 **方法与例题**：上阈3V、下阈2V，低态2.5V仍低，3.2V变高；再降到2.5V仍高，1.8V才低。
- ⚫ **易混易错**：初始输入就在2到3V且历史未知，无法唯一判输出；比较器通常饱和，不能用线性运放虚短。

### 正弦振荡的起振与稳幅
- 🔴 **核心知识**：选频处需满足环路相位条件；起振常令幅值增益略大于1，振幅建立后稳幅使有效环路增益约1。
- 🔵 **方法与例题**：环路增益小于1时扰动衰减；一直大于1而无稳幅，振幅会增大直至削顶，不能得到稳定正弦。
- ⚫ **易混易错**：正反馈不是自动振荡保证，仍需选频和电源供能；相位与幅度要同时满足，稳态条件不等于起振条件。
## 第8章 直流电源、测量与电路读图
### 直流电源、采集链与排障
- 🔴 **核心知识**：电源链产生稳定供电，采集链把物理信号变成数字数据，测量排障确定异常环节；工具按对象选择。
- 🔵 **方法与例题**：交流输入先变压整流滤波稳压；传感器先保护偏置再放大限带ADC；故障先电源地，再工作点与逐级波形。
- ⚫ **易混易错**：把ADC位数提高不能补救供电纹波或前端削顶；万用表平均值正常也不能证明动态波形和全部参数正确。

### 电容滤波纹波估算
- 🔴 **核心知识**：整流后电容峰值附近充电、峰间给负载放电，近似ΔU=I负载Δt/C，先统一安培、秒、法拉。
- 🔵 **方法与例题**：10mA负载、峰间10ms、1000μF时ΔU≈0.1V；电容减半约0.2V，负载增大会加重纹波。
- ⚫ **易混易错**：这只是忽略导通时间的近似；大电容还增充电冲击，不能脱离整流器件、耐压与负载做完整设计。

### 传感器采集链选型
- 🔴 **核心知识**：先保护偏置，再放大或缓冲、抗混叠滤波、ADC和数字处理；每一步对应幅度、负载或频带问题。
- 🔵 **方法与例题**：高源阻传感器接低输入电阻后信号下降，先考虑高输入电阻跟随器；信号过大会饱和，不能只加增益。
- ⚫ **易混易错**：ADC位数高不能修复前端噪声偏置和混叠；滤波过强会丢有用变化，选型需同时核查信号带宽。

### 二极管挡安全初检
- 🔴 **核心知识**：测电阻或二极管前先断电放电，必要脱开一端，再交换表笔测正反两向，排除并联通路影响。
- 🔵 **方法与例题**：普通硅PN结正向常约0.6至0.7V、反向截止；两向近0疑短路，两向截止还需查接触与型号。
- ⚫ **易混易错**：这个检查只能初判开短路，不能证明耐压、放大倍数和动态性能正常；带电量阻可能损表且结果错误。
