# 操作系统原理：重点与易错
## 第1章 操作系统引论
### 操作系统功能与基本特征
- 🔴 **核心知识**：操作系统管理处理机、内存、文件和设备，并提供用户接口与系统调用；并发、共享、虚拟和异步相互关联。
- 🔵 **方法与例题**：批处理看吞吐量，分时看交互响应，实时看截止时间；单核任务交替推进是并发，多核同刻执行才可能并行。
- ⚫ **易混易错**：实时不等于平均速度最快；图形桌面不是整个操作系统；共享必须在权限和同步规则下进行。

## 第2章 操作系统结构与用户接口
### 用户态、内核态与系统调用
- 🔴 **核心知识**：用户态限制特权操作，内核态管理关键资源；系统调用是应用主动请求内核服务的受控接口。
- 🔵 **方法与例题**：读文件经历准备参数、进入内核、检查权限、执行或等待I/O、返回用户态；按触发来源区分系统调用、中断和异常。
- ⚫ **易混易错**：进入内核态不等于一定切换进程；库函数不一定发起系统调用；缺页是可处理异常，不等于程序崩溃。

## 第3章 进程、线程与处理机调度
### 进程、线程与PCB
- 🔴 **核心知识**：进程是资源分配和保护单位，线程是CPU调度执行流；PCB保存进程状态、现场和资源信息。
- 🔵 **方法与例题**：同进程线程共享地址空间和打开文件，但各有程序计数器、寄存器和栈；比较开销时先看是否切换地址空间。
- ⚫ **易混易错**：程序是静态代码，不等于运行中的进程；线程轻量不等于没有切换开销，共享数据仍需同步。

### 进程状态与切换

![进程状态与切换图解](../media/os_process_states.svg)

- 🔴 **核心知识**：就绪只缺CPU，运行正在占用CPU，阻塞正在等事件；切换时需保存旧现场并恢复新现场。
- 🔵 **方法与例题**：运行进程请求I/O会进入阻塞；I/O完成先转就绪，获得CPU后才能运行；时间片到通常由运行转就绪。
- ⚫ **易混易错**：阻塞不能因“调度”直接转运行；进入内核态与进程切换是两个概念，前者可能仍执行同一进程。

### 处理机调度
- 🔴 **核心知识**：FCFS看先到，SJF看短服务，优先级看等级，RR轮流时间片；选择前先明确是否允许抢占。
- 🔵 **方法与例题**：交互响应常用RR，短任务平均等待可比较SJF；计算先排到达与完成，再求周转和等待。
- ⚫ **易混易错**：平均等待低不代表每个任务都短等；RR片太大近FCFS，太小则增加切换与调度的开销。

### 非抢占调度画时间线
- 🔴 **核心知识**：非抢占任务运行中不被后来短任务替代；只在空闲或完成时从已经到达的就绪任务选择。
- 🔵 **方法与例题**：P1到0运行5，P2到1运行3，P3到2运行1；SJF依次P1的0—5、P3的5—6、P2的6—9。
- ⚫ **易混易错**：不能忽略到达时刻预排全部任务；无I/O阻塞的简化题才用等待=完成−到达−服务，先算完成时刻。

### RR时间片与队列
- 🔴 **核心知识**：就绪任务按队列轮转，每次最多运行一片；未完成任务回队尾，新到任务加入就绪队列。
- 🔵 **方法与例题**：同到达P1运行3、P2运行2、片长1，顺序P1、P2、P1、P2、P1，完成时刻分别5和4。
- ⚫ **易混易错**：同时到达与时间片结束的入队先后要服从约定；最后任务可提前结束，不应强行用满时间片。

## 第4章 进程同步与死锁
### 同步、互斥与信号量
- 🔴 **核心知识**：互斥限制同时访问临界资源，同步约束执行先后；P申请或等待，V释放资源或发出通知。
- 🔵 **方法与例题**：记录型P先减1，负则阻塞；V先加1，若≤0则唤醒一个。生产消费设empty=N、full=0、mutex=1，先等数量再取mutex；N=2放一件后为(1,1,1)。
- ⚫ **易混易错**：先持有mutex再等待数量资源可能死锁；P/V必须原子执行，互斥信号量和资源计数信号量作用不同。

### 死锁条件与处理
- 🔴 **核心知识**：死锁同时需要互斥、请求并保持、不剥夺和循环等待；处理包括预防、避免、检测和解除。
- 🔵 **方法与例题**：先画资源等待关系，再判断是否四个条件同时成立；预防要明确破坏哪一个条件，避免则检查未来安全性。
- ⚫ **易混易错**：长期阻塞或饥饿不一定死锁；资源分配图有环在多实例资源下不一定已经死锁。

### 银行家算法与安全序列
- 🔴 **核心知识**：Need=Max−Allocation；以Available为Work，反复寻找Need≤Work的进程并假定完成释放Allocation。
- 🔵 **方法与例题**：每轮写Work、可完成进程和释放量；全部进程能完成则存在安全序列，本次试分配才可接受。
- ⚫ **易混易错**：Work增加的是已分配量，不是最大需求；找不到安全序列表示不安全，不等于当前必然已经死锁。

## 第5章 存储器与虚拟存储器
### 连续分配、分页与分段

![连续分配、分页与分段图解](../media/os_paging_card.svg)

- 🔴 **核心知识**：连续分配可能产生外部碎片；分页固定大小、页内偏移不变；分段按逻辑模块划分并便于共享保护。
- 🔵 **方法与例题**：页号=floor(地址/页大小)，偏移=地址mod页大小，物理地址=页框×页大小+偏移；分段还要检查段长。
- ⚫ **易混易错**：分页主要产生内部碎片，分段可能产生外部碎片；TLB未命中只表示还要查页表，不等于缺页。

### 虚拟存储与页面置换
- 🔴 **核心知识**：虚拟存储按需调页，置换选择牺牲页；OPT看未来、FIFO看装入、LRU看最近使用、CLOCK看访问位。
- 🔵 **方法与例题**：先固定页框数和初始状态，再逐次访问记命中缺页；性能还受局部性、并发度与页框数影响。
- ⚫ **易混易错**：虚拟空间大不表示物理访问同速；TLB未命中不等缺页，FIFO可能出现增加页框反而更多缺页。

### FIFO与LRU命中后状态
- 🔴 **核心知识**：FIFO命中不改装入队列，LRU命中则刷新最近使用顺序；因此下一次淘汰页可能不同。
- 🔵 **方法与例题**：两框访问1、2、1、3：FIFO到3淘汰最早装入1，LRU到3淘汰更久未用2，先画同一命中步骤。
- ⚫ **易混易错**：必须在相同页框数、初始状态和访问串下比较；不能把最近装入误当最近访问或漏计首次缺页。

### CLOCK访问位与指针
- 🔴 **核心知识**：命中把访问位置1；缺页从指针起检查，遇1清0并继续，遇0淘汰，装入后指针向后。
- 🔵 **方法与例题**：[1(1),2(0),3(1)]指向第一框，页4缺页先清页1访问位，再替页2，结果[1(0),4(1),3(1)]。
- ⚫ **易混易错**：指针不是每次回到第一框；CLOCK是近似LRU而非精确最近时间，访问位和页是否在内存不同。

## 第6章 文件管理
### 文件组织、目录与链接
- 🔴 **核心知识**：连续分配随机访问快但扩展难，链接分配扩展方便但定位差，索引分配用索引块支持随机访问。
- 🔵 **方法与例题**：目录按名称找到inode或FCB，再映射到数据块；硬链接共享inode，符号链接保存目标路径。
- ⚫ **易混易错**：inode通常不保存文件名；删除一个硬链接不一定释放数据；符号链接目标删除后可能失效。

## 第7章 输入输出与磁盘管理
### I/O控制、缓冲与SPOOLing
- 🔴 **核心知识**：查询由CPU持续轮询，中断按事件通知，DMA成块直传内存；缓冲协调速度差，SPOOLing把独占设备逻辑共享。
- 🔵 **方法与例题**：按CPU介入程度比较查询、中断、DMA和通道；打印队列先写外存，再由后台进程顺序送往打印机。
- ⚫ **易混易错**：DMA仍需CPU初始化和收尾；缓冲不改变设备本身速度；设备驱动是软件，设备控制器是硬件。

### 磁盘调度
- 🔴 **核心知识**：FCFS按到达，SSTF选最近，SCAN到物理端点反向，LOOK只到最远请求，C-SCAN单向服务。
- 🔵 **方法与例题**：按公平、吞吐与等待比较选择；实际移动题先声明磁道范围和初始方向，再确认回程是否计入。
- ⚫ **易混易错**：没有初始方向不能唯一算SCAN类；SSTF可能饥饿，SSD也没有机械磁头寻道这一过程。

### SSTF逐次选最近
- 🔴 **核心知识**：从当前磁头位置比较所有未服务请求，选距离最小项，服务后以新位置重新比较余下请求。
- 🔵 **方法与例题**：磁头50、请求20与80再10，若同距先向上，则50→80→20→10，移动30+60+10=100。
- ⚫ **易混易错**：最近必须每步重算，不是只按距最初磁头排序；同距的处理约定会影响中间顺序甚至总距离。

### SCAN与LOOK累计距离
- 🔴 **核心知识**：同方向先扫请求，SCAN走到物理端点才反向，LOOK在本方向最后一个请求处就反向。
- 🔵 **方法与例题**：磁道0—99、头50向上、请求20与80：LOOK走50→80→20共90；SCAN经99再到20共128。
- ⚫ **易混易错**：若题目只统计完成所有请求前移动，就不要再加最后无用回程；端点与方向必须先写清。
