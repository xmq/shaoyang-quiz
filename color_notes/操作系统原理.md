# 操作系统原理：重点与易错
## 第1章 操作系统引论
### 操作系统功能与基本特征
- 🔴 **核心知识**：操作系统管理处理机、内存、文件和设备，并提供用户接口与系统调用；并发、共享、虚拟和异步相互关联。
- 🔵 **方法与例题**：批处理看吞吐量，分时看交互响应，实时看截止时间；单核任务交替推进是并发，多核同刻执行才可能并行。
- ⚫ **易混易错**：实时不等于平均速度最快；图形桌面不是整个操作系统；共享必须在权限和同步规则下进行。

## 第2章 操作系统结构与用户接口
### 用户态、内核态与系统调用
- 🔴 **核心知识**：用户态限制特权操作，内核态管理关键资源；系统调用是应用主动请求内核服务的受控接口。
- 🔵 **方法与例题**：读文件经历准备参数、进入内核、检查权限、执行或等待I/O、返回用户态；按触发来源区分系统调用、中断和异常。
- ⚫ **易混易错**：进入内核态不等于一定切换进程；库函数不一定发起系统调用；缺页是可处理异常，不等于程序崩溃。

## 第3章 进程、线程与处理机调度
### 进程、线程与PCB
- 🔴 **核心知识**：进程是资源分配和保护单位，线程是CPU调度执行流；PCB保存进程状态、现场和资源信息。
- 🔵 **方法与例题**：同进程线程共享地址空间和打开文件，但各有程序计数器、寄存器和栈；比较开销时先看是否切换地址空间。
- ⚫ **易混易错**：程序是静态代码，不等于运行中的进程；线程轻量不等于没有切换开销，共享数据仍需同步。

### 进程状态与切换
- 🔴 **核心知识**：就绪只缺CPU，运行正在占用CPU，阻塞正在等事件；切换时需保存旧现场并恢复新现场。
- 🔵 **方法与例题**：运行进程请求I/O会进入阻塞；I/O完成先转就绪，获得CPU后才能运行；时间片到通常由运行转就绪。
- ⚫ **易混易错**：阻塞不能因“调度”直接转运行；进入内核态与进程切换是两个概念，前者可能仍执行同一进程。

### 处理机调度
- 🔴 **核心知识**：FCFS按到达顺序，SJF偏向短作业，优先级调度可能饥饿，RR按时间片轮转并强调交互响应。
- 🔵 **方法与例题**：先画甘特图，再算周转=完成−到达、等待=周转−服务；抢占算法每到新进程或时间片结束都要更新队列。
- ⚫ **易混易错**：RR时间片过大接近FCFS，过小增加切换开销；SJF平均等待较低但不能预知未来时需估计服务时间。

## 第4章 进程同步与死锁
### 同步、互斥与信号量
- 🔴 **核心知识**：互斥限制同时访问临界资源，同步约束执行先后；P申请或等待，V释放资源或发出通知。
- 🔵 **方法与例题**：生产者消费者设empty=N、full=0、mutex=1；先等待empty/full，再进入mutex保护的临界区。
- ⚫ **易混易错**：先持有mutex再等待数量资源可能死锁；P/V必须原子执行，互斥信号量和资源计数信号量作用不同。

### 死锁条件与处理
- 🔴 **核心知识**：死锁同时需要互斥、请求并保持、不剥夺和循环等待；处理包括预防、避免、检测和解除。
- 🔵 **方法与例题**：先画资源等待关系，再判断是否四个条件同时成立；预防要明确破坏哪一个条件，避免则检查未来安全性。
- ⚫ **易混易错**：长期阻塞或饥饿不一定死锁；资源分配图有环在多实例资源下不一定已经死锁。

### 银行家算法与安全序列
- 🔴 **核心知识**：Need=Max−Allocation；以Available为Work，反复寻找Need≤Work的进程并假定完成释放Allocation。
- 🔵 **方法与例题**：每轮写Work、可完成进程和释放量；全部进程能完成则存在安全序列，本次试分配才可接受。
- ⚫ **易混易错**：Work增加的是已分配量，不是最大需求；找不到安全序列表示不安全，不等于当前必然已经死锁。

## 第5章 存储器与虚拟存储器
### 连续分配、分页与分段
- 🔴 **核心知识**：连续分配可能产生外部碎片；分页固定大小、页内偏移不变；分段按逻辑模块划分并便于共享保护。
- 🔵 **方法与例题**：页号=floor(地址/页大小)，偏移=地址mod页大小，物理地址=页框×页大小+偏移；分段还要检查段长。
- ⚫ **易混易错**：分页主要产生内部碎片，分段可能产生外部碎片；TLB未命中只表示还要查页表，不等于缺页。

### 虚拟存储与页面置换
- 🔴 **核心知识**：虚拟存储依赖局部性按需调页；OPT作理论比较，FIFO按装入先后，LRU按最近使用，CLOCK近似LRU。
- 🔵 **方法与例题**：置换题逐次写页框、命中/缺页和淘汰页；FIFO命中不改队列，LRU命中要刷新最近使用次序。
- ⚫ **易混易错**：FIFO可能出现Belady异常；页框过少或并发过高会抖动；虚拟地址空间扩大不代表访问速度更快。

## 第6章 文件管理
### 文件组织、目录与链接
- 🔴 **核心知识**：连续分配随机访问快但扩展难，链接分配扩展方便但定位差，索引分配用索引块支持随机访问。
- 🔵 **方法与例题**：目录按名称找到inode或FCB，再映射到数据块；硬链接共享inode，符号链接保存目标路径。
- ⚫ **易混易错**：inode通常不保存文件名；删除一个硬链接不一定释放数据；符号链接目标删除后可能失效。

## 第7章 输入输出与磁盘管理
### I/O控制、缓冲与SPOOLing
- 🔴 **核心知识**：查询由CPU持续轮询，中断按事件通知，DMA成块直传内存；缓冲协调速度差，SPOOLing把独占设备逻辑共享。
- 🔵 **方法与例题**：按CPU介入程度比较查询、中断、DMA和通道；打印队列先写外存，再由后台进程顺序送往打印机。
- ⚫ **易混易错**：DMA仍需CPU初始化和收尾；缓冲不改变设备本身速度；设备驱动是软件，设备控制器是硬件。

### 磁盘调度
- 🔴 **核心知识**：FCFS按到达，SSTF选最近，SCAN双向电梯式，LOOK只到最远请求，C-SCAN单向服务。
- 🔵 **方法与例题**：先写当前磁道、请求序列和初始方向，再逐步累计移动距离；SSTF每一步都从新位置重新比较。
- ⚫ **易混易错**：SCAN类算法没有方向就不能唯一作答；SSTF可能使远端请求饥饿；SSD没有机械寻道过程。
