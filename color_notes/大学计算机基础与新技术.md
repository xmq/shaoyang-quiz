# 大学计算机基础与新技术：重点与易错

## 第1章 信息、计算与计算思维
### 数据、信息与可信判断
- 🔴 **核心知识**：数据是可处理的符号，信息是数据结合语境后的含义，知识把信息组织成可复用的联系；信息具有依附、共享、时效、价值和真伪等特征。
- 🔵 **方法与例题**：看到“就业率95%”先核对主体、样本、时间、单位和统计口径，再找独立来源；缺少这些条件时只能把截图作为待核信息。
- ⚫ **易混易错**：信息可共享不等于可绕过授权传播；数据多、图表精美或转发量大都不保证结论真实，数据相同也可能因语境不同产生不同信息。

### 计算思维与算法步骤
- 🔴 **核心知识**：计算思维通过分解、抽象、模式识别和算法设计把问题变成可执行步骤；算法应具有明确输入输出、确定性、可行性和有穷性。
- 🔵 **方法与例题**：求最高分时先以首项作当前最大值，再逐项比较更新，遍历结束输出；答场景题要写出状态、判断条件和终止位置。
- ⚫ **易混易错**：计算思维不等于编程；“找出最大值”只是任务描述而非算法，有序数据才能直接二分查找，抽象也不是忽略会改变结果的条件。

## 第2章 信息表示与计算机系统
### 数制转换与容量计算
- 🔴 **核心知识**：位置计数法按位权求值，一位十六进制对应四位二进制；1 Byte等于8 bit，图像和音频容量都应先算总位数再换单位。
- 🔵 **方法与例题**：十六进制2F等于47；1024×768、24位未压缩图像占1024×768×24÷8，即2.25MiB，换算时写清1024或1000口径。
- ⚫ **易混易错**：位数、字长、容量不是同一量；网络速率的Mb/s与文件容量MB相差8倍，压缩文件不能继续直接使用未压缩容量公式。

### 字符、图像与声音编码
- 🔴 **核心知识**：Unicode分配字符码位，UTF-8是其变长编码；位图按像素记录颜色，矢量图记录几何对象；声音数字化经历采样、量化和编码。
- 🔵 **方法与例题**：音频未压缩容量=采样频率×量化位数×声道数×时间÷8；比较图像时分别检查像素数、色深、格式和压缩率。
- ⚫ **易混易错**：字符“1”和整数1编码用途不同，编码不等于加密；分辨率高不必然视觉质量更好，提高采样参数也会同步增大数据量。

### 存储程序与系统组成
- 🔴 **核心知识**：冯·诺依曼机把指令和数据存入存储器，由运算器、控制器、存储器、输入和输出协同；寄存器、Cache、主存和外存构成层次。
- 🔵 **方法与例题**：五大部件按输入→存储→CPU取指处理→输出串起；20根地址线按字节编址最多2^20B=1MiB，不等于实装内存。
- ⚫ **易混易错**：BIOS/UEFI先初始化再引导操作系统；CPU不等于主机，RAM不等于SSD，主频高不保证整机快。

## 第3章 操作系统、文件与软件
### 文件、目录、路径与格式
- 🔴 **核心知识**：目录组织文件，绝对路径从根开始，相对路径依赖当前目录；扩展名提示格式和打开方式，真正格式由文件内容编码决定。
- 🔵 **方法与例题**：普通文件不按修饰键左拖时，同卷通常移动、跨卷通常复制；快捷方式存目标引用，可右击新建或右键拖动后明确创建。
- ⚫ **易混易错**：删除目标会让快捷方式失效，改扩展名不转换内容；拖放要看对象、权限和提示，不能把默认行为推广到所有场景。

### 操作系统资源与工具选择
- 🔴 **核心知识**：操作系统管理处理器、内存、文件和设备；进程是程序的一次运行实例，资源监视工具与文件管理工具承担不同任务。
- 🔵 **方法与例题**：先看本机配置，再用ping测基本连通、tracert看路径；Linux中pwd看当前位置、ls列目录、cd切换、cp复制、mv移动。
- ⚫ **易混易错**：关闭窗口不一定结束后台进程；直接删除安装目录不等于卸载，命令参数和权限依操作系统而异，工具名不能机械互换。

## 第4章 云计算与服务模型
### 云特征与IaaS、PaaS、SaaS
- 🔴 **核心知识**：云计算强调按需服务、资源池化、快速伸缩和可计量；IaaS交付基础资源，PaaS交付运行平台，SaaS直接交付软件功能。
- 🔵 **方法与例题**：在线文档是SaaS，自管操作系统更接近IaaS，只部署代码且平台管理运行环境更接近PaaS；按用户管理到哪层判断。
- ⚫ **易混易错**：虚拟化不自动等于云计算，购买云主机也不消除运维责任；服务模型描述管理边界，公有云和私有云描述部署与治理方式。

### 公有云、私有云与云边协同
- 🔴 **核心知识**：公有云面向多客户，私有云服务单一组织，混合云连接不同环境；边缘靠近数据源低时延处理，云端集中存储和分析。
- 🔵 **方法与例题**：摄像头边缘侧完成实时告警和脱敏，云端长期汇总和更新模型；按时延、带宽、隐私和断网可用性分工。
- ⚫ **易混易错**：云与边缘通常协同而非互相替代，私有云不天然更安全；实时保护不能依赖不稳定远程链路，边缘也需更新和权限管理。

## 第5章 大数据与数据处理
### 数据流程、4V与质量治理
- 🔴 **核心知识**：4V概括数据量、速度、类型和价值；处理流程包括采集、清洗、存储、分析和展示，治理负责质量、权限、元数据和生命周期。
- 🔵 **方法与例题**：城市名称格式不一先统一编码，重复订单先识别去重，再汇总销售额；清洗规则、原值和修改原因应保留记录。
- ⚫ **易混易错**：数据量大不等于质量高，4V也不是硬性认证标准；异常值可能是错误也可能是重要事件，不能为让结果好看而直接删除。

### 挖掘任务与分布式处理
- 🔴 **核心知识**：分类预测类别，回归预测连续值，聚类无标签分组，关联分析找共现关系；HDFS存储，MapReduce计算，YARN管理资源。
- 🔵 **方法与例题**：房价预测是回归，客户分群是聚类，偏离常态的交易是异常检测；若已有欺诈标签训练，则转化为分类任务。
- ⚫ **易混易错**：先看期望输出再选任务，不能只看业务名称；分布式不是简单多买机器，还会产生通信、协调、数据倾斜和恢复开销。

## 第6章 人工智能与机器学习
### AI关系与学习范式
- 🔴 **核心知识**：机器学习是人工智能的重要分支，深度学习通常属于机器学习；监督学习使用标签，无监督学习发现结构，强化学习依靠奖励学习策略。
- 🔵 **方法与例题**：垃圾邮件识别是监督分类，客户自动分群是无监督聚类，游戏智能体按得分调整动作属于强化学习；先看样本与反馈形式。
- ⚫ **易混易错**：人工智能不只包含机器学习，深度学习也不等于全部AI；分类与聚类的关键差别在训练时是否有目标标签。

### 训练、推理与生成式AI
- 🔴 **核心知识**：训练调整模型参数，推理处理新输入；训练集学习、验证集调参、测试集最终评估，生成式AI按学习到的分布产生新内容。
- 🔵 **方法与例题**：训练分高而测试分低先检查过拟合；事实性答案要回查原始来源，高风险结论保留人工复核并保护敏感数据。
- ⚫ **易混易错**：输出流畅不等于事实正确，训练准确率高不保证泛化；反复按测试集调参会造成信息泄漏，测试结果不再可信。

## 第7章 物联网
### 物联网体系与闭环控制
- 🔴 **核心知识**：传感器感知，网络传输，网关汇聚或转换，平台管理规则，执行器改变现场；执行结果再次感知才构成闭环。
- 🔵 **方法与例题**：智慧灌溉按“湿度采集→网络传输→规则判断→阀门执行→状态反馈”说明，每一环都要写清输入和输出。
- ⚫ **易混易错**：设备能联网不等于完整物联网系统，只上传数据属于监测而非闭环；网关与平台职责不同，传感器不会自动完成业务判断。

### 设备身份、安全与失联
- 🔴 **核心知识**：设备标识、网络地址和用户身份职责不同；安全需要唯一身份、最小权限、加密通信、安全更新、日志监测和网络分区。
- 🔵 **方法与例题**：温度突跳180℃时核对量程、变化率和其他传感器，先进入受限控制并告警；断网时按预设安全状态运行。
- ⚫ **易混易错**：加密不能修复弱口令和过大权限，云端失联也不能让现场失控；单点异常直接驱动执行器可能把测量故障扩大为事故。

## 第8章 区块链
### 哈希、签名、共识与链式记录
- 🔴 **核心知识**：哈希用于发现内容变化，数字签名验证来源和完整性，共识让多节点对记录形成一致，前区块哈希把记录按顺序连接。
- 🔵 **方法与例题**：旧交易被修改后摘要变化，后续区块的前驱摘要无法对应；说明防篡改时要同时写链式校验、多副本与共识约束。
- ⚫ **易混易错**：防篡改不等于数据绝对真实或不可删除，哈希不是加密原文；合法主体写入错误事实时，链本身无法判断现实真假。

### 区块链选型与智能合约
- 🔴 **核心知识**：公有链开放参与，联盟链由许可成员维护，私有链由单组织控制；智能合约是按条件执行的程序，仍受代码和外部数据影响。
- 🔵 **方法与例题**：多机构缺少单一可信中心且需共同追溯时可评估联盟链；单组织内部高性能事务通常使用普通数据库更直接。
- ⚫ **易混易错**：共享数据不必然需要上链，智能合约不等于法律合同自动正确；还需比较吞吐、隐私、治理、升级和长期维护成本。

## 第9章 计算机发展与典型应用
### 计算机发展与应用分类
- 🔴 **核心知识**：计算机代际常按电子管、晶体管、集成电路和大规模集成电路概括；应用含科学计算、数据处理、过程控制和辅助设计等。
- 🔵 **方法与例题**：气象数值模拟侧重科学计算，工资结算侧重数据处理，生产线反馈调节侧重过程控制；按主要任务而非设备名称判断。
- ⚫ **易混易错**：分代不表示某一年全球设备同时换代；使用计算机不等于都属于AI，同一系统可包含多种应用但题目通常问主要用途。

### 信息系统与数字化建设
- 🔴 **核心知识**：信息系统由人员、流程、数据、软件、硬件和网络共同组成；建设还需数据治理、权限、安全、维护与责任分工。
- 🔵 **方法与例题**：医院预约冲突先检查排班流程、号源责任和重复患者数据，再决定软件如何约束；答题要连接业务问题与系统措施。
- ⚫ **易混易错**：买设备或部署软件不等于完成数字化；硬件更快不能修复错误流程和脏数据，自动化旧问题还可能让错误传播更快。

## 第10章 新一代信息技术的综合应用
### 按目标与约束组合技术
- 🔴 **核心知识**：先明确目标和输入输出，再检查时延、规模、隐私、可靠性、联网和多方信任，最后选择云、边缘、大数据、AI或区块链。
- 🔵 **方法与例题**：校园能耗由物联网采集、边缘五秒内关停、云端长期分析，有标注样本再用AI预测；按目标—约束—技术—风险作答。
- ⚫ **易混易错**：技术堆叠不会自动提高质量，每增加一项都会增加接口和运维成本；普通统计无需大数据，可信中心存在时也未必需要区块链。
