# 数字电子技术：重点与易错

## 第1章 数制和码制
### 数制、BCD与格雷码

- 🔴 **核心知识**：数制按位权表示数值；8421BCD逐位编码十进制数字；反射格雷码相邻码字只变1位。
- 🔵 **方法与例题**：十进制13：二进制1101、BCD为0001 0011；二进制1011按g=b⊕(b>>1)得格雷1110。
- ⚫ **易混易错**：BCD的1010～1111不是合法单个十进制数位；格雷码不可直接按8421权相加。

### 二进制小数按位权求值

- 🔴 **核心知识**：小数点右第k位权值2^−k；整数转进制除基取余倒序，小数乘基取整正序。
- 🔵 **方法与例题**：101101.01₂=32+8+4+1+1/4=45.25；0.25×2取0，再×2取1，得0.01₂。
- ⚫ **易混易错**：分组转十六进制时，小数部分从小数点向右每4位分组，补0不改变数值。

## 第2章 逻辑代数与门电路
### 门电路、有效电平与三态

- 🔴 **核心知识**：与要求全部1，或要求至少1，非取反；低有效须按端口标记判断。高阻态表示输出停止主动驱动。
- 🔵 **方法与例题**：VOH最小2.4 V而接收器VIH要求3.5 V，高电平不保证兼容；开漏输出需上拉。
- ⚫ **易混易错**：逻辑值不固定为某一电压；高阻不是逻辑0，普通推挽输出不可随意并联。

## 第3章 逻辑函数的表示与化简
### 逻辑代数、最小项与卡诺图

- 🔴 **核心知识**：最小项含全部变量且只在一种组合为1；卡诺图按格雷码排列，圈相邻2^k格消去变化变量。
- 🔵 **方法与例题**：F=Σm(1,3,5,7)，三变量ABC中这些项C恒1、A/B变化，四格圈得F=C。
- ⚫ **易混易错**：边界首尾相邻，斜角不相邻；无关项可用可不用，规定0不得圈入1组。

## 第4章 组合逻辑电路
### 编译码器、MUX与加法器

- 🔴 **核心知识**：编码器把有效输入转成代码，译码器按代码激活输出；MUX选数据，全加器含低位进位。
- 🔵 **方法与例题**：4线高有效优先编码I3最高，0110编码10且有效；全加器S=A⊕B⊕Cin。
- ⚫ **易混易错**：普通编码器通常假设一路有效；使能、低有效和无输入状态要读功能表。

### 组合冒险与采样边界

- 🔴 **核心知识**：竞争是路径到达先后不同，冒险是这种延迟差导致短暂错误脉冲；稳定真值表不描述瞬态。
- 🔵 **方法与例题**：F=AB+非A·C，B=C=1，A翻转时理论应常1；两支延迟可能形成短低脉冲，可加冗余BC覆盖。
- ⚫ **易混易错**：增加冗余只针对相应冒险；同步采样仍须等信号稳定并满足建立、保持时间。

### 用MUX拆分逻辑函数

- 🔴 **核心知识**：2选1且使能有效时Y=非S·D0+S·D1，S=0取D0、S=1取D1。
- 🔵 **方法与例题**：实现Y=AB：令S=A、D0=0、D1=B；A=0输出0，A=1输出B。
- ⚫ **易混易错**：无效使能时输出按具体器件规定；低有效使能和反相输出须另处理。

### 全加器的和位与进位

- 🔴 **核心知识**：全加器三个输入满足普通数值A+B+Cin=2Cout+S；S=A⊕B⊕Cin，Cout=AB+(A⊕B)Cin。
- 🔵 **方法与例题**：A=B=Cin=1，总和3=二进制11，故Cout=1、S=1；总和2则Cout=1、S=0。
- ⚫ **易混易错**：和位留在本位，进位送高位；表达式中的逻辑“+”不是普通整数加法。

## 第5章 触发器与时序逻辑电路
### RS、JK、D、T触发器

- 🔴 **核心知识**：高有效RS：S=1,R=0置1，S=0,R=1置0，00保持、11禁用；JK的11翻转，D采样D，T=1翻转。
- 🔵 **方法与例题**：按S,R顺序，10置1、01置0；JK特性Q+=J非Q+非K·Q，T特性Q+=T⊕Q。
- ⚫ **易混易错**：先认输入顺序、有效电平和触发方式；锁存器电平敏感，边沿触发器只在有效沿采样。

### 状态表、状态图与时序分析

- 🔴 **核心知识**：状态方程由当前输入及旧状态求Q+；状态表和状态图表达相同转移，输出需另判Moore/Mealy。
- 🔵 **方法与例题**：T=1、初态Q=0，连续三次有效边沿后1、0、1；必须每次用更新前状态求新状态。
- ⚫ **易混易错**：异步清零可不等时钟；违反建立/保持时间可能亚稳，不能保证读到某一固定值。

## 第6章 寄存器、计数器与存储器
### 寄存器与同步计数器

- 🔴 **核心知识**：寄存器暂存位组；同步计数器各触发器共用时钟。模N所需位数为满足2^n≥N的最小n。
- 🔵 **方法与例题**：模10需4位且有6个未用状态；模4状态00→01→10→11→00。
- ⚫ **易混易错**：计数循环还须检查未用状态是否能回到有效循环；能编码不等于自启动。

### 存储器容量与扩展

- 🔴 **核心知识**：容量=字数×字长；位扩展增加每地址位数，字扩展增加地址数并用片选区分芯片。
- 🔵 **方法与例题**：两片1K×4成1K×8，共10位地址；两片1K×8成2K×8，需11位地址，高位作片选。
- ⚫ **易混易错**：共用数据总线时只允许目标芯片驱动；RAM随机存取与易失性是不同分类依据。

### 移位寄存器逐拍跟踪

- 🔴 **核心知识**：明确位序、移位方向、串入值及有效边沿；整组新状态由同一拍旧状态生成。
- 🔵 **方法与例题**：Q3Q2Q1Q0初态1011、右移补0，逐拍0101、0010、0001、0000；移出1、1、0、1。
- ⚫ **易混易错**：循环移位高位接原低位，和补0不同；不要把移位当普通数值加1。

### 计数器状态到T激励

- 🔴 **核心知识**：T激励由T=Q⊕Q+反求；两位模4加法计数器T0=1、T1=Q0。
- 🔵 **方法与例题**：旧态01时T1=T0=1，两个触发器同时翻转成10；改D触发器则D0=非Q0、D1=Q1⊕Q0。
- ⚫ **易混易错**：同一拍T1必须用边沿前旧Q0；先统一计算各位激励，再同时更新，T输入与D输入不可套同一规则。

## 第7章 脉冲波形与数模、模数转换
### 脉冲、555与施密特触发

- 🔴 **核心知识**：单稳态触发后返回唯一稳态；无稳态持续振荡；施密特用上下阈值整形。标准555阈值约VCC/3、2VCC/3。
- 🔵 **方法与例题**：单稳态电容从0充至2VCC/3，t=RC ln3≈1.1RC；100 kΩ、10 μF约1.1 s。
- ⚫ **易混易错**：1.1RC只适用标准单稳态；施密特输出方向及555复位条件按实际接法。

### ADC/DAC分辨率与采样

- 🔴 **核心知识**：n位有2^n种码，均匀步长Δ=范围/2^n；ADC抽样量化编码，DAC按码权重产生模拟量。
- 🔵 **方法与例题**：3位Vref=8 V，理想单极DAC的101对应D=5，U=8×5/8=5 V，最高111为7 V。
- ⚫ **易混易错**：分辨率不是绝对精度；采样率不足会混叠，位数增加不能补偿时间信息丢失。

### 脉冲周期与占空比

- 🔴 **核心知识**：频率f=1/T，高电平占空比D=tH/T；每次计算先明确“有效脉宽”是高段还是低段。
- 🔵 **方法与例题**：tH=2 ms、T=8 ms，D=25%、f=125 Hz；tL=6 ms。
- ⚫ **易混易错**：周期包括高低两段；低有效脉冲的有效占比可能为tL/T，不能默认等于高电平占空比。

### 施密特双阈值整形

- 🔴 **核心知识**：指定上升超过3 V输出高、下降低于2 V输出低时，2～3 V内保持原状态。
- 🔵 **方法与例题**：从低态升2.5 V仍低、3.2 V高；再降2.4 V仍高、1.8 V低，回差1 V。
- ⚫ **易混易错**：历史未知且输入2.5 V时状态不能唯一判断；反相接法的高低方向可相反。
