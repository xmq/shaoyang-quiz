# 数字电子技术：重点与易错

数字逻辑可作为组成原理的前置知识；完整电路分析按电子岗位范围学习。颜色区分结论、方法与易错，不表示考频。

## 一、数字信号与数制

### 二进制与编码
- 🔴 **核心知识**：数字电路用离散逻辑状态表示信息，二进制数按位权求值；BCD用四位二进制分别编码十进制数字，不等于普通二进制整体转换。
- 🔵 **方法与例题**：十进制12的二进制为1100，8421 BCD为0001 0010。先判断题目要求数值表示还是某种编码，再进行转换。
- ⚫ **易混易错**：逻辑0和1由电平范围定义，不必对应精确0 V与1 V。补码、原码、BCD和格雷码有不同目的。

## 二、基本逻辑门

### 从输入求输出
- 🔴 **核心知识**：与门要求条件同时成立，或门至少一个成立，非门取反，异或在两输入不同时为1；与非和或非可组合实现其他逻辑。
- 🔵 **方法与例题**：两输入A=1、B=0，则AB=0，A+B=1，异或=1；写真值表时列齐所有输入组合，n个二值输入共有2的n次方种组合。
- ⚫ **易混易错**：逻辑代数的加号表示或，不是普通算术加法；异或不等于包含或。带反相标记的输入输出需先明确有效电平。

## 三、逻辑代数基础

### 化简与等价
- 🔴 **核心知识**：吸收、分配和德摩根定律用于化简。卡诺图把相邻项安排为只差一个变量，合并2的整数次方个相邻格以消去变化变量。
- 🔵 **方法与例题**：AB+A非B=A(B+非B)=A。两输入卡诺图若A=1的两格均为1，可以合并得到A。
- ⚫ **易混易错**：卡诺图相邻包含边界相接，不含斜对角。无关项可按有利化简使用，但必须确实是不会出现或输出不关心的条件。

## 四、组合逻辑电路

### 从功能到表达式
- 🔴 **核心知识**：组合电路当前输出仅由当前输入决定。分析先列输入输出含义、真值表和表达式，再化简实现；编码器、译码器、多路选择器功能不同。
- 🔵 **方法与例题**：半加器和位为A异或B，进位为AB；全加器还需考虑低位进位。多路选择器按选择信号把某一路数据送到输出。
- ⚫ **易混易错**：门延迟可能导致瞬时竞争冒险，稳态真值表不能完整描述时间行为；译码器输出是否低有效必须看型号约定。

## 五、触发器与时序逻辑

### 状态与有效边沿
- 🔴 **核心知识**：时序电路输出还与状态有关。D触发器在规定有效边沿按D更新Q；锁存器按有效电平开放，二者不能混同。
- 🔵 **方法与例题**：上升沿D触发器在三个上升沿采到1、0、1，忽略异步控制且满足时序要求，Q依次更新为1、0、1；边沿之间保持。
- ⚫ **易混易错**：不能把D在任意时刻变化都画到Q上；建立保持时间不满足时行为可能不可靠。异步置位复位可能优先于时钟。

## 六、寄存器、计数器与半导体存储器

### 状态数量与容量
- 🔴 **核心知识**：寄存器保存位组，移位寄存器按时钟移位，计数器按状态序列变化。n个二值存储位最多表示2的n次方种状态。
- 🔵 **方法与例题**：模10计数至少需4位状态编码，因为3位仅8种，4位有16种；1024×8位存储器容量为8192 bit，即1024 B。
- ⚫ **易混易错**：4位不表示一定是模16，可能只使用其中10种状态。容量计算要分清地址数量、每地址位宽和字节换算。

## 七、脉冲电路与数模、模数转换

### 分辨率与转换
- 🔴 **核心知识**：A/D把模拟量转换为数字码，D/A按码产生模拟输出；分辨率与位数有关，采样率描述转换频度，二者不等同。
- 🔵 **方法与例题**：理想8位ADC把0到5 V分为256个量化区间时，区间宽度为5/256 V，约19.53 mV；输入增加一个区间通常对应相邻码。
- ⚫ **易混易错**：最大码对应电压还取决于端点映射定义，不能混用除以256与255的模型。位数多不自动保证实际精度高，噪声和非线性同样影响结果。
