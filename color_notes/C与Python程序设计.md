# C与Python程序设计：重点与易错

## 第1章 程序设计与算法
### 算法、流程与执行

- 🔴 **核心知识**：算法具有有穷性、确定性、可行性、输入和输出；程序常用顺序、选择、循环与函数组织。
- 🔵 **方法与例题**：最大值用非空序列首项初始化，再逐项比较更新；外层1…n、内层1…i次数n(n+1)/2，为O(n²)。
- ⚫ **易混易错**：0可作初值只适用于已明确的值域；全负数时固定0会错，空输入须先约定。

### 编译、解释与程序错误

- 🔴 **核心知识**：编译翻译为目标形式；解释在运行中执行源程序或中间形式；现代实现可组合两者。
- 🔵 **方法与例题**：语法错误违反语法；运行异常在执行时出现；逻辑错误可正常运行却结果不符需求。
- ⚫ **易混易错**：C越界等未定义行为不保证报异常；Python常生成字节码再解释执行，并非每次逐句重新翻译源文。

## 第2章 数据类型、变量与常量
### 类型、变量与转换

- 🔴 **核心知识**：C声明变量类型，Python名称绑定有类型对象；C无内建字符串类型，通常以char数组加结束符表示。
- 🔵 **方法与例题**：C double x=7/2先整数除得3再变3.0；(double)7/2得3.5；Python int(3.9)向0截断为3。
- ⚫ **易混易错**：int大小依实现；float有限精度；Python可变的是名字绑定，不是对象“没有类型”。

## 第3章 运算符与表达式
### 运算符、除法与短路

- 🔴 **核心知识**：C整数/向0截断，Python //向下取整；逻辑&&/||或and/or会短路。
- 🔵 **方法与例题**：C x=0; 0&&++x不执行右侧，x仍0；−7/2为−3，Python −7//2为−4。
- ⚫ **易混易错**：优先级不等求值先后；C未排序的重复修改不可强算；Python and/or返回操作数，不必为bool。

## 第4章 顺序结构与输入输出
### 输入输出与顺序跟踪

- 🔴 **核心知识**：C stdio.h提供scanf/printf，Python input返回str、print输出。顺序结构逐句更新状态。
- 🔵 **方法与例题**：scanf %d接int*、%f接float*、%lf接double*；printf %f接double。Python int(input())后才能按整数加。
- ⚫ **易混易错**：检查scanf成功赋值项数；%s限制宽度并预留结束符；输入失败不可读未初始化变量。

## 第5章 选择结构
### 条件与多分支

- 🔴 **核心知识**：if/else按真假选择；Python elif形成互斥分支，C switch按整型/枚举值跳到case。
- 🔵 **方法与例题**：等级90/80/60应从高向低测试；85跳过90、命中80后不再执行后续elif。
- ⚫ **易混易错**：C else配最近未配对if，Python靠缩进；switch缺break会贯穿后续语句；=不是==。

## 第6章 循环结构
### 循环状态与边界

- 🔴 **核心知识**：循环含初始化、继续条件、循环体、更新；while可0次，C do…while至少1次，Python for遍历元素。
- 🔵 **方法与例题**：range(1,5)为1,2,3,4；C for遇continue先做更新再判断，while遇continue直接回条件。
- ⚫ **易混易错**：break只退最近循环；range步长不为0；Python循环else遇break不执行。

## 第7章 函数与模块化程序设计
### 函数、参数与返回

- 🔴 **核心知识**：形参在定义中、实参在调用中；C按值传递，Python调用建立形参与对象的绑定。
- 🔵 **方法与例题**：C需通过指针修改调用方对象；Python向列表append可见，但形参重新赋一个列表不改变外部名字绑定。
- ⚫ **易混易错**：函数返回与打印不同；C返回普通局部变量地址会悬空；默认可变参数在Python中会跨调用复用。

### C与Python名字作用域

- 🔴 **核心知识**：调用时为每层保存参数、局部变量和返回位置；区分局部名字、共享对象、全局/静态状态。
- 🔵 **方法与例题**：C static int n=0; ++n跨两次调用返回1/2；普通局部每次初始化0则均返回1。
- ⚫ **易混易错**：作用域与存储期不同；Python列表别名会共享修改，赋值不自动深拷贝。

### 递归调用与逐层返回

- 🔴 **核心知识**：递归需可达终止条件，每次调用向终点推进，返回按调用栈逆序展开。
- 🔵 **方法与例题**：fact(3)→3×fact(2)→3×2×fact(1)，fact(1)=1，逐层得2、6。
- ⚫ **易混易错**：递归不是同时输出所有层；要计活动调用深度，缺终点或方向错误会无限递归/栈耗尽。

### 预处理与static局部状态

- 🔴 **核心知识**：#define作文本替换，#include包含声明；作用域是名字可见范围，存储期是对象存在时间。
- 🔵 **方法与例题**：SQUARE(x)写((x)*(x))仍不能安全传i++；函数static int n=0; return ++n;连续调用得1、2。
- ⚫ **易混易错**：宏无函数类型检查；static局部只初始化一次，名字仍限块内，不自动成为全局可见。

## 第8章 数组、字符串与Python组合数据
### C数组与字符串

- 🔴 **核心知识**：数组连续存同类型元素，长n合法下标0…n−1；字符串以空字符结束，长度不含结束符。
- 🔵 **方法与例题**：char s[6]="cat"，sizeof s=6、strlen(s)=3；a[i]等价*(a+i)，数组名通常转首元素指针。
- ⚫ **易混易错**：数组不是指针变量，sizeof数组与sizeof指针不同；C越界不保证报错，字符串容量须含结束符。

### Python列表、元组、字典与集合

- 🔴 **核心知识**：列表可变，元组/字符串不可变；字典键与集合元素须可哈希；字典保存键值，集合去重。
- 🔵 **方法与例题**：a=[[1]]; b=a.copy(); b[0].append(2)后a=[[1,2]]，外层复制但内层共享。
- ⚫ **易混易错**：空{}为字典，空集合set()，单元组(1,)；字典插入顺序不等于键排序，含列表的元组也不可哈希。

## 第9章 C指针、结构体与文件
### C指针与地址

- 🔴 **核心知识**：指针变量保存指针值；&取址、*解引用，指针加1跨过一个所指类型对象。
- 🔵 **方法与例题**：int占4B，a首址1000、a=[10,20,30]，p=a后p+1为1004；p++;*p=25使a变[10,25,30]。
- ⚫ **易混易错**：末尾后一指针可形成不可解引用；空、未初始化、悬空指针不可访问，free后别名也失效。

### C结构体

- 🔴 **核心知识**：结构体把不同类型成员合成记录，变量用.、指针用->访问；数组成员仍不能整体赋值。
- 🔵 **方法与例题**：struct Student {int id; float score;}; s={1,85}; s.id为1；整体赋值复制成员，指针成员复制地址。
- ⚫ **易混易错**：大小需计对齐填充；union共享存储、enum给整数具名、typedef起类型别名，均不同于创建结构体实例。

### C文件与资源管理

- 🔴 **核心知识**：FILE*表示流；fopen成功后仍须检查读写结果，fclose释放流；r读、w创建/截断、a追加，b为二进制。
- 🔵 **方法与例题**：循环以fgets/fscanf/fread实际返回值控制；fread返回完整元素个数。malloc成功后按所有权free。
- ⚫ **易混易错**：feof只在读取尝试到达末尾后置位；free不自动清指针，文件和动态对象都要明确生命周期。

### 二维数组与指针声明

- 🔴 **核心知识**：int *p[3]是指针数组，int (*q)[3]是数组指针；int a[2][3]通常转为指向第一行的指针。
- 🔵 **方法与例题**：int4B，a首址1000，q=a，q+1为1012，*(*(q+1)+2)访问地址1020的a[1][2]。
- ⚫ **易混易错**：q+1跨一整行，不能只加4；函数指针int (*f)(int)不同于返回指针函数int *f(int)。

## 第10章 Python异常、模块与文件
### Python按异常类型分支

- 🔴 **核心知识**：try放可能失败操作，except匹配类型，else在try无异常时执行，finally通常用于清理。
- 🔵 **方法与例题**：int("abc")触发ValueError；文件不存在FileNotFoundError；编码不符UnicodeDecodeError。
- ⚫ **易混易错**：先写具体异常再写广泛父类；不要空except吞全部错误，finally不能当“成功分支”。

### with文件读写与编码

- 🔴 **核心知识**：文本模式在str与字节之间编码/解码，二进制模式读写bytes；with按上下文协议释放资源。
- 🔵 **方法与例题**：with open(path,"r",encoding="utf-8") as f:逐行读，再显式转换数值；写CSV通常配newline=""。
- ⚫ **易混易错**：w会截断原文件；read可能占大量内存；encoding用于文本模式，自动关闭不保证数据处理逻辑正确。

### CSV转换统计与格式化

- 🔴 **核心知识**：CSV字段先按格式解析成文本，再显式转换数值；不能用简单split逗号处理所有含引号字段。
- 🔵 **方法与例题**：成绩文本80、90，逐行累计(total,count)=(80,1)→(170,2)，f"{total/count:.1f}"输出85.0。
- ⚫ **易混易错**：空文件先检count>0；缺列/非法数值要处理；JSON解析与CSV表格读取不是同一接口。

## 第11章 C与Python程序模型比较
### C与Python语义比较

- 🔴 **核心知识**：先确定语言、类型与版本，再按规则执行；两者控制结构相似，但类型、存储和运算语义不同。
- 🔵 **方法与例题**：C整数−7/2=−3、−7%2=−1；Python −7//2=−4、−7%2=1，都满足商×除数+余数=原数。
- ⚫ **易混易错**：Python无++/--运算符；C数组不能直接重绑定赋值；自动内存管理不替代文件及时关闭。
